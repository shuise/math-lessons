# 数学教材参考汇总

## 概述

本目录收录了 `books/` 中所有教材的学习摘要，涵盖以下教材：

> 共 **19 本教材/套书**（含 1 本合集拆分出的 7 册），覆盖数学思维、数学教育、教学研究、趣味数学、工具书、逻辑学等多种类型。
