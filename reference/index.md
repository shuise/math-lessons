# 数学教材参考汇总

## 概述

本目录收录了 `books/` 中所有教材的学习摘要，聚焦**知识点讲解思路**和**做题技术**，为课程设计提供参考。

> 共 **26 份参考摘要**，覆盖数学教育理论、教学实践、解题方法论、思维训练、趣味启蒙等多种类型。
