# 数学颂

**作者:** 阿兰·巴迪欧 (Alain Badiou)、吉尔·艾利 (Gilles Haéri)

**核心主题:** 从哲学角度辩护数学的意义，呼吁数学应该走出象牙塔和考试牢笼，成为每个人改变生活的力量。

---

## 前言：必须拯救数学

巴迪欧指出当前数学面临的两个危机：

1. **应试数学**：数学沦为考试进阶的工具，学生只学如何解题而不理解数学之美。
2. **精英数学**：数学被少数专家垄断，成为与大众隔绝的秘教。

巴迪欧认为，数学的意义是普世性的，数学应该成为大众共同掌握的力量。

## 哲学和数学，一对老情侣的故事

- 从柏拉图开始，哲学与数学就紧密相连
- 巴迪欧的哲学体系中将**数学**视为四种"真理程序"之一（另外三种是：政治、艺术、爱）
- 数学是最基础的真理程序——它处理的是纯粹的、可公理化的知识

## 数学谈些什么？

- 数学谈论的是**无限**和**永恒**
- 数学对象不是经验的、物理的，而是理念的、抽象的
- 数学真理不依赖于经验观察

## 数学与幸福

- 数学学习可以带来智力上的愉悦
- 数学赋予我们认识世界本质的能力
- 通过数学，我们可以接触到"不可感知"的真实

## 数学与生活变革

- 数学不是中立的工具，它具有改变世界的力量
- 掌握数学思维 = 掌握一种批判性的认识工具
- 数学可以帮助我们穿透意识形态的迷雾

## 关键概念

| 概念 | 解释 |
|------|------|
| 真理程序 | 巴迪欧认为只有数学、政治、艺术、爱能产生真理 |
| 本体论 | 巴迪欧断言"数学就是本体论"——数学研究的是存在本身 |
| 事件 | 打破既定秩序、开辟新可能性的突发状况 |
| 情势 | 我们所处的、有特定结构的世界状态 |
| 数学之病 | 应试数学和精英数学都扭曲了数学的真正意义 |
