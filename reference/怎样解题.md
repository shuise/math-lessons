# 《怎样解题》学习摘要

**作者**: 波利亚  
**类型**: 数学方法论经典  
**核心主题**: 解题的系统方法

---

## 一、讲解思路：教师如何帮助学生

### 1. 帮助的艺术
- **不多不少**：帮助应当恰使学生有一份合理的工作，不能替学生做
- **不显眼**：让学生感觉自己是在独立工作
- **顺乎自然**：提出学生自己可能会产生的问题，指出学生自己可能会想出的步骤

### 2. 问题引导法（核心教学技巧）
教师通过提问引导学生思考，而不是直接给出答案：

| 阶段 | 关键问题 |
|------|----------|
| 理解问题 | "未知数是什么？已知数据是什么？条件是什么？" |
| 拟定计划 | "你知道一道与此有关的题目吗？你能利用它吗？" |
| 执行计划 | "你能清楚地看出这个步骤是正确的吗？" |
| 回顾反思 | "你能检验这个结果吗？能用不同方法推导吗？" |

### 3. 模仿与实践
- 解题就像游泳，是一种实际技能
- 学生通过观察教师解题 → 模仿 → 实践来学习
- 教师在全班面前解题时，应当把自己的思路展示出来，边做边问自己

## 二、解题技术：四步解题法

### 第一步：理解题目
**技术要点**：
- 画图并标上符号
- 把条件分部分写出来
- 检查条件是否足以确定未知数

### 第二步：拟定方案
**核心技术**：
- **看着未知数**：想一个具有相同或相似未知数的熟悉问题
- **类比**：寻找相似问题
- **分解与重组**：将复杂问题分解
- **特殊化与一般化**：先试特殊情形
- **逆向思维**：从目标倒推
- **辅助元素**：引入辅助线、辅助未知数

### 第三步：执行方案
- 检查每一步
- 你能证明每一步都是正确的吗？

### 第四步：回顾反思
**最容易被忽视但最重要的步骤**：
- 检验结果
- 用另一种方法推导
- 能否把结果/方法用到其他问题？

## 三、经典启发法详解

| 方法 | 含义 | 教学示例 |
|------|------|----------|
| 分解与重组 | 把大问题拆成小问题 | 解复杂应用题时先分步 |
| 特殊化 | 先试简单情形找规律 | 鸡兔同笼先从总数少的情况开始 |
| 类比 | 找相似问题借思路 | 分数运算类比整数运算 |
| 逆向思维 | 从目标倒推 | 证明题从结论反推条件 |
| 辅助问题 | 引入中间问题 | 求对角线先求面对角线 |
| 归纳猜想 | 先猜后证 | 找规律题先列前几项观察 |

---

## 四、对课程设计的启示

1. 每个例题都按"理解→计划→执行→反思"流程编排
2. 例题中标注引导性问题（如"想一想：未知数是什么？"）
3. 保留"回顾反思"环节，检查结果和方法
4. 教师角色是引导者而非答案提供者
