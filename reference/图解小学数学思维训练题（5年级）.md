# 《图解小学数学思维训练题（5年级）》学习摘要

**作者**: 彭林  
**类型**: 思维训练/培优  
**核心主题**: 5年级数学高阶思维训练——以图解方式解题

---

## 目录（25章）

| 模块 | 章节内容 |
|------|---------|
| 计算 | 小数加减/乘除巧算、分数巧算、单位分数 |
| 几何 | 多边形内角和、三角形面积、组合图形面积、长方体正方体、不规则体积、图形变换 |
| 应用题 | 平均数、盈亏、鸡兔同笼、相遇问题、追及问题、流水行船 |
| 计数 | 加法原理与乘法原理、包含与排除 |
| 思维 | 数阵规律、周期问题、取胜妙策、推理问题 |
| 代数 | 方程问题、列方程解应用题 |

---

## 核心特色：图解解题法

本书区别于普通习题集的核心特色是**用图解方式呈现解题思路**：
- 线段图解决行程问题
- 面积图解决鸡兔同笼
- 数阵图探索规律
- 方格图解决组合问题
