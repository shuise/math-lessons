# 魔鬼数学：大数据时代，数学思维的力量

**作者:** 乔丹·艾伦伯格 (Jordan Ellenberg)

**核心主题:** 运用数学思维理解世界，避免常见的数学误用和认知偏差。

---

## 第一部分：线性

- **线性思维**：人们倾向于用线性关系理解世界，但现实往往是非线性的。
- **线性函数**：形如 `y = mx + b` 的函数，变化率恒定。
- **非线性现象**：复利增长、人口爆炸、疫情传播等，不能用线性模型描述。
- **微分思想**：将非线性问题在局部近似为线性问题。

## 第二部分：推理

- **统计显著性**：p 值的含义与误用。"小概率事件并不少见"——如果做足够多的试验，总会有看似显著的结果出现。
- **死鲑鱼实验**：对一条死鲑鱼做 fMRI 扫描，发现其"大脑"对人类情感有反应——这是多重比较未修正导致的假阳性。
- **多重比较修正**：当同时检验大量假设时，需要提高显著性门槛（如 Bonferroni 校正）。
- **圣经密码**：在长篇文本中总能找到"隐藏"的模式，这只是概率在起作用。

## 第三部分：期望值

- **期望值定义**：`E(X) = Σ(P(x) × x)`，即所有可能结果的概率加权平均值。
- **彩票分析**：强力球彩票的期望值远低于售价（通常每 2 美元仅值约 0.60 美元）。
- **期望值不是期望的结果**：彩票要么中要么不中，"期望值"是大量重复下的平均结果。
- **终身年金保险**：哈雷彗星的发现者哈雷最早用期望值给保险定价，考虑了年龄因素。
- **大数定律**：试验次数越多，实际结果越接近期望值。

## 第四部分：回归

- **回归到均值**（高尔顿发现）：极端值之后往往跟随着更接近平均值的观测结果。
- **回归分析**：用数学模型描述变量之间的关系。
- **回归谬误**：将回归到均值误认为因果效应（如"新秀墙"现象）。
- **辛普森悖论**：分组趋势与整体趋势相反的现象（如伯克利性别偏见案）。

## 第五部分：存在

- **欧几里得公理**：几何学的公理体系，特别是第五公设（平行公设）。
- **非欧几何**：
  - **双曲几何**（波尔约、罗巴切夫斯基）：过一点有无数条平行线。
  - **球面几何**（黎曼）：任意两条直线（大圆）都相交，无平行线。
- **形式主义**：数学是符号游戏，公理和定理的含义由我们赋予。"点"和"直线"可以是任何满足公理的对象。
- **法诺平面**：只有 7 个点和 7 条直线的有限几何。

## 关键概念总结

| 概念 | 解释 |
|------|------|
| 线性思维陷阱 | 将非线性问题简化为线性，导致错误判断 |
| 统计显著性 | p 值不能直接表示"结果有多重要" |
| 期望值 | 长期平均结果，不是单次预期 |
| 回归到均值 | 极端值后趋向平均值 |
| 辛普森悖论 | 分组与总体统计结果相反 |
| 非欧几何 | 改变平行公设，打开全新几何世界 |
| 形式主义 | 数学是公理系统的逻辑推导 |
