# 数与代数（核心骨架）

三个阶段的递进关系：每个课件只依赖前面已学过的知识，保证学生始终只需要"加减乘除 + 已学内容"就能理解。

---

## 阶段一：数 — 从"数数"开始

### 1. 自然数、零与十进制
- 一一对应（数羊、结绳记事）
- 记数符号的演变（埃及象形→罗马数字→印度-阿拉伯数字）
- **位值制**：为什么 111 的三个"1"不一样大？
- **零**：印度人 9 世纪的革命——零作为占位符
- 十进制：为什么是 10？还有哪些常见的其他进制？

### 2. 分数
- 起源：分饼、分地——"不够分"怎么办？
- 真分数、假分数、带分数
- 等值分数：为什么 1/2 = 2/4 = 3/6？
- 通分与约分（找公分母）
- 分数四则运算（加减乘除）
- 倒数（古巴比伦的 igum/igibum）

### 3. 负数
- 起源：中国人的算筹（红正黑负）→ 印度人的"债务"→ 笛卡儿的数轴
- 用欠债、温度计、楼层（地下）理解负数
- 数轴：正数在右，负数在左，零在中间
- 正负数运算规则（为什么负负得正？用数轴和"欠债取消"解释）
- 绝对值：到零的距离

---

## 阶段二：式 — 从"数"到"字母"

### 4. 代数式与字母表示数
- 起源：韦达（16 世纪）和笛卡儿——用字母代替数
- 什么是代数式：数字 + 字母 + 运算符号
- 代数式的值：把字母换成具体数字
- 单项式与多项式
- 系数、次数、常数项

### 5. 整式运算
- 同类项与合并（花拉子米的"对消"）
- 分配律：a(b + c) = ab + ac
- 多项式乘法（FOIL）：(a+b)(c+d) = ac + ad + bc + bd
- 完全平方公式：(a+b)² = a² + 2ab + b²（用面积图解释）
- 平方差公式：(a+b)(a-b) = a² - b²

### 6. 因式分解与分式
- 因式分解：把多项式"拆回"乘法形式
- 提公因式法
- 十字相乘法（二次三项式 → 两个一次因式相乘）
- 分式：分母含字母的代数式
- 分式的基本性质与约分、通分
- 分母为什么不能为零？

## 阶段三：方程 — 天平上的未知数

### 7. 一元一次方程
- 起源：古巴比伦泥板问题、古埃及阿姆士纸草书、花拉子米的"还原与对消"
- 天平比喻：等式两边平衡
- 等式的性质：两边同时加减乘除（不为零）同一个数，等式仍然成立
- 解法（用逻辑推导每一步，不是背步骤）：
  - 去分母 → 两边乘公分母（等式性质：乘）
  - 去括号 → 分配律展开（已学：课件 5）
  - 移项 → 两边加减同一个数（等式性质：加减）
  - 合并同类项 → 花拉子米的"对消"（已学：课件 5）
  - 系数化为 1 → 两边除以系数（等式性质：除）
- 检验：代入原方程

### 8. 分式方程
- 起源：古巴比伦的倒数问题（igum/igibum）
- 核心思路：去分母 → 化为一元一次方程
- 致命陷阱：增根——为什么必须检验？
  - 去分母时乘了含未知数的式子，可能引入"伪解"
  - 检验方法：代入原方程，看分母是否为零
- 解法步骤与检验（已学基础：课件 2 分数、课件 6 分式、课件 7 一元一次方程）

### 9. 一元二次方程
- 起源：古巴比伦的几何解法 → 花拉子米的"凑完全平方" → 邦贝利与虚数
- 标准形式：ax² + bx + c = 0（a ≠ 0）
- 四种解法（每种解释由来，从基本知识推导）：
  - 直接开平方法：x² = k → x = ±√k（已学：课件 5 平方根概念）
  - 配方法：花拉子米的几何思路——把 x² + bx 拼成 (x + b/2)²（已学：课件 5 完全平方公式）
  - 公式法：由配方法推出求根公式 x = (-b ± √(b²-4ac)) / 2a
  - 因式分解法：化为 (x-m)(x-n)=0 → x=m 或 x=n（已学：课件 6 十字相乘）
- 根的判别式 Δ = b² - 4ac：
  - Δ > 0：两个不等实根
  - Δ = 0：两个相等实根
  - Δ < 0：无实根（邦贝利发现：引入虚数后有解，但不要求）
- 韦达定理：x₁ + x₂ = -b/a，x₁·x₂ = c/a（用因式分解推导）
