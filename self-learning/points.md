# 数与代数（核心骨架）

---

## 方程

### 一元一次方程
- 解法步骤：去分母 → 去括号 → 移项 → 合并同类项 → 系数化为 1

### 分式方程
- 解法与增根检验

### 一元二次方程
- 解法：
  - 直接开平方法
  - 配方法
  - 公式法（求根公式）
  - 因式分解法
- 根的判别式（$\Delta = b^2 - 4ac$）：
  - $\Delta > 0$：两个不等实根
  - $\Delta = 0$：两个相等实根
  - $\Delta < 0$：无实根
- 韦达定理（根与系数关系）：
  $$x_1 + x_2 = -\frac{b}{a}, \quad x_1 x_2 = \frac{c}{a}$$
