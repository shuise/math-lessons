分式方程

起源：未知数怎么跑到分母里了？

普通方程里，未知数 x 在分子上：2x + 3 = 7。但如果 x 跑到分母里了呢？比如：「一个人完成一项工作需要 x 天，他每天完成 1/x。如果他先做 2 天，再和另一个人合作 3 天完成，求 x。」

这种问题自然就产生了分母中含未知数的方程。古人在解决工程问题、行程问题时，经常遇到这种情况。

分式方程要解决的核心问题：未知数出现在分母里，不能直接按一元一次方程解。但思路是一样的——想办法把分母去掉，变回我们熟悉的整式方程。

不过，分式方程有一个陷阱：去分母时，我们假设分母不为 0。如果解出的 x 恰好让某个分母为 0，那这个解就是假的（叫"增根"），必须舍去。这个坑，古人也是踩过很多次才发现的。

一、什么是分式方程？

分式方程：分母中含有未知数的方程。

比如：1/(x-2) = 3，x/(x+1) = 2，2/(x+1) + 3/(x-1) = 5/(x²-1)。

注意分母不能为 0！比如 1/(x-2) = 3 中，x 不能等于 2。

二、核心思路：去分母

分式方程 → 两边同时乘以最简公分母 → 变成整式方程 → 按一元一次方程解。

就像把分数方程"翻译"成整数方程，然后再解。

三、逻辑推导：为什么能去分母？

等式的性质：等式两边同时乘以同一个非零的数，等式仍然成立。

所以我们可以两边同时乘以所有分母的最小公倍数（最简公分母），把所有分母同时消掉。前提是我们要确保乘的表达式不为 0。

例子：解 1/(x-2) = 3

两边乘 (x-2)：1 = 3(x-2)
去括号：1 = 3x - 6
移项：3x = 7
解出：x = 7/3
检验：1/(7/3-2) = 1/(1/3) = 3 ✓

四、致命的陷阱：增根

什么是增根？解方程时，我们两边乘了一个含有未知数的式子。如果解出的 x 恰好让这个式子等于 0，那么我们就相当于在等式两边乘了 0——这会把假解也"制造"出来。

所以分式方程解完后必须检验！把解代入原方程，确保每个分母都不为 0。让分母为 0 的解就是增根，必须舍去。

有增根的例子：解 x/(x-1) - 1/(x-1) = 2

去分母：x - 1 = 2(x-1) → x - 1 = 2x - 2 → x = 1

检验：x=1 代入原方程，分母 x-1 = 0，原方程无意义！
结论：x=1 是增根，这个方程无解。

五、完整解题步骤

第 1 步：找最简公分母（所有分母的最小公倍数）

第 2 步：两边同时乘最简公分母，去掉所有分母

第 3 步：解得到的整式方程

第 4 步：检验！确保每个分母 ≠ 0

综合例子：解 2/(x+1) + 3/(x-1) = 5/(x²-1)

x²-1 = (x+1)(x-1)，最简公分母是 (x+1)(x-1)

两边乘 (x+1)(x-1)：2(x-1) + 3(x+1) = 5
2x - 2 + 3x + 3 = 5 → 5x + 1 = 5 → x = 4/5

检验：x=4/5 时，x+1 ≠ 0，x-1 ≠ 0，分母都不为 0 ✓

小结

  • 分式方程 = 分母中有未知数的方程
  • 解法：去分母 → 变整式方程 → 解方程
  • 必须检验！解出的 x 不能让任何分母为 0
  • 让分母为 0 的解叫"增根"，必须舍去
