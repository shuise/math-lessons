# 自学课件

工作目录 self-learning

知识点范围 points.md

## 生成规则
1. 每个知识点一个课件 xxxx.html，所有课件汇总成一个列表 index.html
2. 每个知识点都要用最通俗的语言解释给小学生（只有加减乘除知识 + 本课件之前已学过的课件内容），最开始要交代起源，介绍为什么会有这概念，具体是为了解决什么问题？又具体是谁怎么提炼出来的方法？要详细解释概念，定义，逻辑推导，最后再给出公式和证明。
3. 每个知识点要给出一些挑战性的问题，要求学生自己去思考和解决。要给出一些拓展阅读。
4. 最后给几个习题，标注难度等级，给出提示和答案查看。
5. 每个课件开头列出前置知识（已学过的课件编号），确保学生不会遇到未学过的概念。
6. 解法不能只列操作步骤，必须解释每一步的**逻辑依据**（例如：移项不是"移过去变号"，而是"等式两边同时加减同一个数"的推论）。
7. 如果使用数形结合，或者用图形解释思路，一定要给出对应的图形，且要详细解释图形的含义，必要的话采用动画形式。


## 课件结构模板
每个课件按以下顺序组织：
1. 前置知识（列出已学课件编号）
2. 起源（历史故事，为什么需要这个概念）
3. 概念与定义（用日常比喻解释）
4. 逻辑推导（从基础出发，一步步推出结论）
5. 公式与证明（推导的自然结果，不是死记硬背）
6. 挑战性问题（2-3 个，需要学生自己思考）
7. 拓展阅读（推荐书目、相关历史故事）
8. 习题（4 道，标注难度等级，含思路提示和答案查看）

## 设计原则（来自参考书籍）
- **波利亚（《怎样解题》）**：教学是"顺乎自然地帮助学生"，每一步引导学生自己发现问题
- **Lockhart（《一个数学家的叹息》）**：数学是"说明的艺术"，不是食谱；用比喻、故事、图形解释，而非列步骤
- **风云老师（《中小学数学要义》）**：数学内容应围绕核心脉络，保持概念之间的逻辑连贯
- **《极简数学》**：用日常比喻（天平、分饼、温度计、欠债）让抽象概念具象化
- 以及 sources 中的所有其他书籍
