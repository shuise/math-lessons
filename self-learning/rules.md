# 自学课件

工作目录 self-learning

知识点范围 points.md

## 生成规则
1. 每个知识点一个课件 xxxx.html，所有课件汇总成一个列表 index.html
2. 每个知识点都要用最通俗的语言解释给小学生（只有加减乘除知识），最开始要交代起源，介绍为什么会有这概念，具体是为了解决什么问题？又具体是谁怎么提炼出来的方法？ 要详细解释概念，定义，逻辑推导，最后再给出公式和证明。
3. 每个知识点要给出一些挑战性的问题，要求学生自己去思考和解决。要给出一些拓展阅读。

## UI 说明
1. 默认 mobile 模式，兼容 desktop 模式
2. 所有课件都要在 mobile 模式下测试，确保在 mobile 设备上正常显示
3. 所有课件都要在 desktop 模式下测试，确保在 desktop 设备上正常显示
