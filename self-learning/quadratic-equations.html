一元二次方程

起源：一块田有多大？

4000 年前的古巴比伦，人们已经会解一元二次方程了。他们用楔形文字刻在泥板上，记录了大量这样的问题：

"一个正方形的面积加上它的边长等于 3/4，求边长。"翻译成现代数学就是：x² + x = 3/4。

巴比伦人用了一种"凑完全平方"的方法（就是后来的配方法），一步步算出答案。但他们没有负数的概念，只取正数解。

到了公元 9 世纪，波斯数学家花拉子米在《代数学》中系统总结了配方法，并给出了几何解释——用正方形和长方形的面积来直观理解 x² + bx 为什么能配成 (x + b/2)²。

又过了 800 年，法国数学家韦达（François Viète，1540–1603 年）发现了根与系数的关系——不用解方程，就能知道两根之和与两根之积。这就是韦达定理。

一元二次方程要解决的核心问题：未知数出现了平方，方程最多有两个解。怎么最快、最准地找到它们？

一、什么是二次方程？

一元一次方程里，x 最多只有一次方：2x + 3 = 7。现在，x 变成了平方：x² = 9。

x² = 9 有两个解：x = 3 和 x = -3（因为 3² = 9，(-3)² = 9）。

一元二次方程：未知数最高次数是 2 的方程。标准形式：ax² + bx + c = 0（a ≠ 0）。

二、四种解法（从简单到通用）

方法一：直接开平方法（最简单）

如果方程能写成 x² = a 或 (x+m)² = a 的形式，直接开平方：x = ±√a

a > 0 → 两个解，a = 0 → 一个解，a < 0 → 无实数解

(x-2)² = 9 → x-2 = ±3 → x = 5 或 x = -1

方法二：配方法（花拉子米的方法，最体现思想）

花拉子米的几何解释：把 x² + bx 想象成一个边长为 x 的正方形，加上一个宽为 x、长为 b/2 的矩形，再加一个（每边都是 b/2 的矩形）。拼在一起是一个边长为 x + b/2 的大正方形，面积是 x² + bx + (b/2)²。

所以 x² + bx 想变成完全平方，需要加上 (b/2)²。这就是"配方"。

解 x² + 6x + 5 = 0：
x² + 6x = -5（常数移到右边）
x² + 6x + 9 = -5 + 9（两边加 9，因为 (6/2)² = 9）
(x + 3)² = 4
x + 3 = ±2 → x = -1 或 x = -5

方法三：公式法（最通用，从配方法推导出来）

对于 ax² + bx + c = 0（a ≠ 0），解为：

x = (-b ± √(b² - 4ac)) / (2a)

这个公式其实就是把配方法写成通用形式——对所有二次方程都适用！

解 2x² - 4x - 6 = 0：a=2, b=-4, c=-6
x = (4 ± √(16 + 48)) / 4 = (4 ± 8) / 4 → x = 3 或 x = -1

方法四：因式分解法（最快，但需要能分解）

x² - 5x + 6 = 0 → (x-2)(x-3) = 0 → x = 2 或 x = 3
原理：如果 A × B = 0，那么 A = 0 或 B = 0。

三、根的判别式：Δ = b² - 4ac

不用解方程，看一眼 Δ 就知道有几个解：

  • Δ > 0：两个不同的实数解
  • Δ = 0：一个实数解（两个相等，叫"重根"）
  • Δ < 0：没有实数解（因为 √负数 在实数范围内没有意义）

为什么？看求根公式：x = (-b ± √Δ) / (2a)。如果 Δ < 0，√Δ 不存在，就没有实数解。

四、韦达定理：根与系数的关系

如果 ax² + bx + c = 0 的两个根是 x₁ 和 x₂，那么：

x₁ + x₂ = -b/a，x₁ · x₂ = c/a

证明：从求根公式，x₁ = (-b + √Δ)/(2a)，x₂ = (-b - √Δ)/(2a)。两根相加：√Δ 抵消，得 -2b/(2a) = -b/a。两根相乘：用平方差公式 (u+v)(u-v) = u²-v²，得 (b²-Δ)/(4a²) = (b²-(b²-4ac))/(4a²) = 4ac/(4a²) = c/a。

验证：x² - 5x + 6 = 0 的根是 2 和 3。
2 + 3 = 5 = -(-5)/1 ✓ · · 2 × 3 = 6 = 6/1 ✓

小结

  • 一元二次方程 ax² + bx + c = 0，最多两个解
  • 四种解法：直接开平方 → 配方 → 公式 → 因式分解
  • Δ = b² - 4ac 判断有几个解
  • 韦达定理：x₁ + x₂ = -b/a，x₁ · x₂ = c/a
