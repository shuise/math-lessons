一元一次方程

起源：人类为什么要发明方程？

4000 年前，古埃及人遇到一个问题：一堆粮食，加上它的 1/4，总共是 15 斗。这堆粮食原来有多少？

他们用"试位法"（也叫"假位法"）来解决：先猜一个数，代入算，看差多少，再按比例调整。比如猜 4 斗，4 + 1 = 5，不是 15。15 是 5 的 3 倍，所以答案是 4 × 3 = 12 斗。

这种方法虽然有效，但很麻烦。大约 3000 年后，波斯数学家花拉子米（Al-Khwarizmi，公元 780–850 年）写了一本书《还原与对消的科学》，第一次系统地把方程解法写成了规则。"还原"（al-jabr）就是把负项移到等号另一边变正，"对消"（al-muqabala）就是合并同类项。英语里的 algebra（代数）就来自 al-jabr 这个词。

方程要解决的核心问题：已知一些条件，找出一个未知的数。用字母 x 代表这个未知数，写出等式，然后按规则解出 x。

一、什么是方程？

想象一架天平，左右两边是平衡的。如果左边放了一个 x 和一个 3 克的砝码，右边放了一个 10 克的砝码，那么：

x + 3 = 10

这个含有未知数 x 的等式，就叫方程。

"一元"意思是只有一个未知数，"一次"意思是未知数的最高次数是 1（没有 x²）。

天平原理：方程就像一个天平，等号两边是平衡的。你在一边做了什么，另一边也要做同样的事，天平才不会倾斜。

二、概念与定义

方程的解（根）：能让方程成立的 x 的值。比如 x + 3 = 10 的解是 x = 7，因为 7 + 3 = 10。

解方程：找到方程的解的过程。

移项：把一项从等号一边移到另一边，同时改变它的符号。比如从 x + 3 = 10 得到 x = 10 - 3。

三、逻辑推导：花拉子米的"还原与对消"

第 1 步：去分母（如果有分数）—— 等式两边同时乘以所有分母的最小公倍数，把分母消掉。因为等式两边乘相同的数，等式仍然成立。

第 2 步：去括号（如果有括号）—— 用分配律展开。a(b + c) = ab + ac。

第 3 步：移项（花拉子米的"还原"）—— 把含有 x 的项移到等号左边，常数项移到等号右边。移项要变号！为什么？因为你实际上是在两边同时加减同一个数。

第 4 步：合并同类项（花拉子米的"对消"）—— 把同类项合并成一项。

第 5 步：系数化为 1—— 两边同时除以 x 的系数。如果 2x = 6，两边除以 2 得 x = 3。

四、公式与证明

一元一次方程的标准形式：ax + b = 0（a ≠ 0）

解的公式：x = -b/a

证明：ax + b = 0 → ax = -b（两边减 b）→ x = -b/a（两边除以 a）

完整例子：解 (2x + 1)/3 - (x - 1)/2 = 1

去分母：两边乘 6（3 和 2 的最小公倍数）→ 2(2x+1) - 3(x-1) = 6
去括号：4x + 2 - 3x + 3 = 6
移项：4x - 3x = 6 - 2 - 3
合并：x = 1
检验：(2×1+1)/3 - (1-1)/2 = 3/3 - 0 = 1 ✓

小结

  • 方程 = 含有未知数的等式，就像一架天平，两边平衡
  • 花拉子米总结了两大法宝：还原（移项变号）+ 对消（合并同类项）
  • 五步法：去分母 → 去括号 → 移项变号 → 合并 → 系数化 1
  • 解出 x 后一定要代入原方程检验
