修订记录

这里记录课件的重要修订：新增了什么、修正了什么、为什么改。每次修订都会写清日期和涉及的页面，方便核对学习内容是否有更新。修订依据来自《改进》清单（初中课程文档设计）。

2026-09-18第 3 批修订

界面统一改版（ui 风格 #1 #2 #3 #4 #5）

  • 全站换成同一套界面样式：正文区域是白底，外围留浅灰色；板块之间用细线分隔，卡片和方框都不加圆角（只有按钮有 2 像素的小圆角），字体更大更清楚。以前每页各自一套颜色（黄色、粉色、紫色…），现在统一成一种，翻页时不再跳来跳去（ui #2）。
  • 所有样式集中写进 style.css 一个文件。页面里不再直接在标签上写样式，改成用统一的类名（ui #1 #3）。原来题库单独的 question-bank.css 也并了进来，这个文件已删除。
  • 手机上看：左右留白一致，内容不会挤出屏幕。电脑上看：内容居中，最宽 720 像素，不会拉得很长难读（ui #4）。
  • 标题、段落、表格、按钮、答题框、提示框的大小和间距全部对齐，同一类内容外观一致（ui #2）。
  • 逐页检查了所有跳转链接，全部有效；顺手修正了 模拟考试 — 统计与概率 引用了错误目录样式文件的问题（ui #5）。
  • 所有图形（数轴、几何图、统计图）的颜色和动画保持原样，只把它们的样式挪到了 style.css，没有改动任何内容和功能。

2026-09-18第 2 批修订

新增功能：我的题库（功能改进 #1 #2 #3）

  • 所有带习题的页面（共 60 个，包括 38 个课程页和 22 套模拟卷、奥数卷）：每道题旁边新增「⭐ 加入题库」按钮。觉得哪道题需要多练几遍，点一下就收进题库，再点一次可取消（功能 #1）。
  • 答错的题目会自动收进题库，不用自己动手，方便以后复习错题（功能 #2）。同时会记下当时填错或选错的答案，这个记录只存在本地、不会在题库页面显示，留作以后帮你分析错在哪。
  • 课程列表：新增「📝 我的题库」标签页。收进来的题目可以重新作答，提示、答案、分析等功能和原页面完全一样；每道题可以随时「移出题库」，也有「清空题库」按钮。题库里不放「加入题库」按钮，避免重复收藏（功能 #3）。
  • 题库存放在浏览器的本地存储（localStorage）里，关掉浏览器再打开也不会丢。换电脑或换浏览器时题库不会跟着走。
  • 新增文件：question-bank.js（题库功能脚本），只在使用题库功能的页面加载。题库样式已并入 style.css，不再单独维护 CSS 文件。

2026-09-12第 1 批修订

新增专题页（入口在课程列表"专题精讲"）

  • 数轴详解 — 原点、正方向、单位长度三要素；数与点的对应；用数轴理解相反数、绝对值、加减法（代数 #2）。
  • 计算工具箱 — 六件运算工具（加减乘除、乘方、开方）；特殊数字 1、0、-1；估算与近似值；科学计数法与对数表思想；单位换算（代数 #4 #5 #6 #7 #10）。
  • 立体与平面转化 — 立体图形展开/折叠为平面图形、平面图形围成立体图形，覆盖柱、锥、台、球等常见图形（几何 #1）。

代数部分增补

  • 有理数的加减乘除：新增"六、乘方：重复的乘法"小节——底数与指数、负数乘方的符号规律、(-2)² 与 -2² 的区别，配套 2 道新习题（代数 #3）。
  • 分数：新增"六、小数化分数：方法与技巧"——三步法（去小数点当分子、按位数定分母、约到最简）、分数化小数、循环小数小技巧，配套 2 道新习题（代数 #9）。
  • 实数：新增拉马努金手工估算 √ 值的实际例子（代数 #11）。
  • 自然数：新增质数扩展阅读——定义、筛法、为什么 1 曾经是后来又不是质数（代数 #12）。
  • 整式运算：新增杨辉三角一节（代数 #13）。
  • 因式分解与分式：新增公式法（平方差、完全平方）并调整为第一种方法（代数 #14）。
  • 分式方程：在讲解分式方程前先加入"分式乘除与通分"热身引导（代数 #15）。
  • 一元一次方程、二元一次方程组、分式方程、一元二次方程：解题前新增"清点工具箱"强调框——每一步只允许使用加减乘除、乘方、开方六件工具，并标注每步对应哪件工具（代数 #8）。

几何部分增补

  • 三角形：新增外角讲解——定义、图示、外角定理及证明、例题与习题，后续章节编号相应顺延（几何 #2）。
  • 圆：新增三角形内切圆与内心说明——定义、性质、图示、例题与习题（几何 #3）。

修复与其他

  • 全等三角形、三角形、负数、相交线与平行线：修正 CSS 引用错误（指向了不存在的 lessons 目录样式），统一改用本目录 style.css（代数 #1）。
  • 概率初步：修复概率公式渲染错误（分子放错位置）；页面末尾新增两个数学游戏链接（其他 #1）。
  • 课程列表：新增"专题精讲"分组，收录 3 个专题页；底部审核横幅加入本"修订记录"入口。

说明：修订遵循两条原则——① 只用朴素方法，不超纲；② 定理与规则要求一字不差地记住，并说明数学的严谨性。后续修订将继续追加在本页顶部。
