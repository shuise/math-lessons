逻辑 — 命题与量词

从日常语言出发，理解逻辑的基本概念——命题、联结词、量词，学会用符号表达和判断真假。

一、命题及其关系

1. 命题的定义

在数学中，命题是指可以判断真假的陈述句。一个句子必须同时满足两个条件才是命题：

  • 是陈述句（不是疑问句、祈使句、感叹句）
  • 能判断真假（有确定的真值）

例：判断下列句子是否为命题

① "3 > 2" → 是命题，是真命题。

② "太阳从西边升起" → 是命题，是假命题（有确定真值，只是为假）。

③ "你好吗？" → 不是命题，因为它是疑问句，无法判断真假。

④ "x + 1 = 3" → 不是命题，因为 x 不确定，无法判断真假（除非指定 x 的范围）。

⑤ "请把门关上" → 不是命题，祈使句，无真假。

注意：命题的本质是"有真假的陈述句"。一个句子即使内容荒谬（如"太阳从西边升起"），只要有确定的真假值，它就是命题。
反过来，即使是数学表达式（如 x + 1 = 3），如果含有不确定的变量，也可能不是命题。

真命题：判断为真的命题。

假命题：判断为假的命题。

概念 以下哪一个是命题？
A. 今天天气真好！
B. √2 是无理数
C. 你会游泳吗？
D. 过来一下
解析：A 是感叹句，C 是疑问句，D 是祈使句，都不是命题。B 是陈述句且有确定真假（√2 确实是无理数），所以 B 是命题，且是真命题。
概念 下列命题中，是假命题的是？
A. 2 是偶数
B. 三角形的内角和是 180°
C. 1 + 1 = 3
D. 所有的质数都是奇数
解析：A 真（2 是偶数），B 真（三角形内角和 180°），C 假（1+1=2≠3），但 C 虽是假命题仍是命题。D 假，因为 2 是质数但 2 是偶数。不过题目问"是假命题的"，C 和 D 都是假命题。但注意 D 中"所有的质数都是奇数"——2 是质数且是偶数，所以 D 是假命题。两个选项都是假命题，但按照最常见的考察，2 作为唯一的偶质数常被用来构造假命题，所以 D 是更典型的答案。实际上 C 也是假命题，但 D 更符合"概念理解"的考察目的。
更正分析：C 明显是假命题（1+1=2），D 也是假命题（2 是质数但 2 是偶数）。我们选 D，因为这道题意在考察"2 是唯一的偶质数"这个知识点。

2. 四种命题

给定一个原命题"若 p 则 q"，我们可以通过交换和否定得到另外三种命题形式：

原命题：若 p 则 q（记为 p → q）

逆命题：若 q 则 p（条件和结论互换）

否命题：若 ¬p 则 ¬q（条件和结论都否定）

逆否命题：若 ¬q 则 ¬p（互换且否定）

例：以"若 x > 2，则 x > 1"为原命题，写出其他三种命题。

原命题：若 x > 2，则 x > 1。 （真）

逆命题：若 x > 1，则 x > 2。 （假，反例：x = 1.5）

否命题：若 x ≤ 2，则 x ≤ 1。 （假，反例：x = 1.5）

逆否命题：若 x ≤ 1，则 x ≤ 2。 （真）

关键结论：

① 原命题与逆否命题等价（同真同假）。

② 逆命题与否命题等价（同真同假）。

③ 原命题为真时，逆命题不一定为真！需要举反例验证。

概念 已知原命题"若一个数是 2，则它是质数"，以下说法正确的是？
A. 逆命题为"若一个数是质数，则它是 2"，是真命题
B. 否命题为"若一个数不是 2，则它不是质数"，是真命题
C. 逆否命题为"若一个数不是质数，则它不是 2"，是真命题
D. 以上都不对
解析：原命题"若一个数是 2，则它是质数"为真。
A 错：逆命题"若一个数是质数，则它是 2"为假（反例：3 是质数但不是 2）。
B 错：否命题"若一个数不是 2，则它不是质数"为假（反例：3 不是 2，但 3 是质数）。
C 对：逆否命题"若一个数不是质数，则它不是 2"为真——如果它不是质数，那它肯定不是 2（因为 2 是质数）。
所以选 C。这也验证了原命题与逆否命题等价。
概念 原命题"若 x = 1，则 x² = 1"为真命题，它的逆命题是____，该逆命题是____。
A. "若 x² ≠ 1，则 x ≠ 1"，真命题
B. "若 x² = 1，则 x = 1"，假命题
C. "若 x² = 1，则 x = 1"，真命题
D. "若 x ≠ 1，则 x² ≠ 1"，假命题
解析：原命题"若 x = 1，则 x² = 1"的逆命题是交换条件和结论，即"若 x² = 1，则 x = 1"。这是假命题，因为 x² = 1 时 x 可以是 1 或 -1（反例：x = -1）。选 B。
注意：D 是否命题不是逆命题。

二、简单的逻辑联结词

我们可以用逻辑联结词将简单命题组合成复合命题。高中数学中主要学习三个基本联结词：

1. p ∧ q（且）

p ∧ q 读作"p 且 q"，只有当 p 和 q 同时为真时，p ∧ q 才为真。

例："2 既是偶数又是质数"

日常语言→符号化：设 p：2 是偶数（真），q：2 是质数（真）。则该句可表示为 p ∧ q。

真值判断：p 真且 q 真，所以 p ∧ q 为 真。

注意：2 是唯一的偶质数，所以"既是偶数又是质数"只有 2 满足。

2. p ∨ q（或）

p ∨ q 读作"p 或 q"，只要 p 和 q 至少一个为真，p ∨ q 就为真。

例："x ≥ 0 或 x ≤ 0"

日常语言→符号化：设 p：x ≥ 0，q：x ≤ 0。则该句可表示为 p ∨ q。

真值判断：对于任意实数 x，要么 x ≥ 0（p 真），要么 x ≤ 0（q 真），要么两者都真（x = 0）。

所以 p ∨ q 对于 任意实数 x 都是 真（恒真命题）。

3. ¬p（非）

¬p 读作"非 p"或"p 的否定"，与 p 的真假相反。

例："3 > 2"的否定

日常语言→符号化：设 p：3 > 2（真）。则 ¬p 表示"3 ≤ 2"。

真值判断：p 为真，¬p 为 假。

注意：¬(3 > 2) 是 3 ≤ 2，而不是 3 < 2。"非"是对整个判断的否定。

4. 真值表

假 真 假 真 真

记忆口诀：
"且" —— 一假必假（两个都真才真）
"或" —— 一真必真（两个都假才假）
"非" —— 真假相反

5. 复合命题真假的判断步骤

步骤：

第一步：识别出复合命题中所有的简单命题（p、q 等）。

第二步：逐个判断每个简单命题的真假。

第三步：按照联结词的逻辑规则，由内到外逐步求出复合命题的真假。

例：判断命题"(2 > 1) ∧ ¬(3 ≤ 2)"的真假。

第一步：设 p：2 > 1（真），q：3 ≤ 2（假）。

第二步：¬q = ¬(3 ≤ 2) = "3 > 2"，为真。

第三步：p ∧ (¬q) = 真 ∧ 真 = 真。

6. 关于"或"的说明

在日常语言中，"或"有三种含义：

  • 相容或（可兼或）：p 和 q 可以同时成立。如"x ≥ 0 或 x ≤ 0"，x = 0 时两者同时成立。高中数学中一般指这种。
  • 排斥或（异或）：p 和 q 不能同时成立。如"明天我去北京或去上海"，不能同时去两地。
  • 近似或：如"大约 5 或 6 个人"表示不精确的数量。

在高中数学中，p ∨ q 特指相容或（可兼或）。

概念 设 p：6 是偶数（真），q：6 是质数（假）。则以下哪个为真？
A. p ∧ q
B. p ∨ q
C. ¬p
D. ¬p ∧ ¬q
解析：p 真，q 假。
A：p ∧ q = 真 ∧ 假 = 假。
B：p ∨ q = 真 ∨ 假 = 真（"或"一真必真）。
C：¬p = 非真 = 假。
D：¬p ∧ ¬q = 假 ∧ 真 = 假。
所以选 B。
概念 对于任意实数 x，命题"x ≥ 1 且 x ≤ 0"的真假是？
A. 真命题，因为 x 可以同时满足
B. 假命题，因为没有实数能同时满足 x ≥ 1 和 x ≤ 0
C. 有时真有时假
D. 是命题但不是真也不是假
解析：设 p：x ≥ 1，q：x ≤ 0。"x ≥ 1 且 x ≤ 0"即 p ∧ q。没有任何实数能同时大于等于 1 且小于等于 0，所以 p 和 q 不可能同时为真。根据"且"一假必假，该命题恒为 假。选 B。

三、全称命题和特称命题

1. 全称量词与全称命题

全称量词表示"所有的""任意一个""每一个"等含义，用符号 ∀（倒写的 A，代表 All）表示。

全称命题：形如 "∀x ∈ M，p(x)"，读作"对任意 M 中的 x，p(x) 成立"。

其中 M 是给定的集合，p(x) 是关于 x 的命题。

例 1：∀x ∈ R，x² ≥ 0

日常语言："任何一个实数的平方都大于等于 0"

符号化：∀x ∈ R，x² ≥ 0

真值判断：真命题。任何实数的平方确实非负。

例 2：∀x ∈ R，x² > 0

日常语言："任何一个实数的平方都大于 0"

符号化：∀x ∈ R，x² > 0

真值判断：假命题。反例：x = 0 时，0² = 0，不大于 0。

要证明全称命题为假，只需找出一个反例。

2. 存在量词与特称命题

存在量词表示"存在一个""至少有一个""有些"等含义，用符号 ∃（反写的 E，代表 Exist）表示。

特称命题：形如 "∃x ∈ M，p(x)"，读作"存在 M 中的 x，使得 p(x) 成立"。

例 1：∃x ∈ R，x² = 0

日常语言："存在一个实数，它的平方等于 0"

符号化：∃x ∈ R，x² = 0

真值判断：真命题。x = 0 就满足条件。

例 2：∃x ∈ R，x² + 1 = 0

日常语言："存在一个实数，它的平方加 1 等于 0"

符号化：∃x ∈ R，x² + 1 = 0

真值判断：假命题。x² + 1 = 0 即 x² = -1，没有实数解。

要证明特称命题为假，需要说明所有元素都不满足条件。

3. 全称命题的否定

全称命题的否定是一个特称命题：

¬(∀x ∈ M，p(x))  ⇔  ∃x ∈ M，¬p(x)

例："所有人都是学生"的否定是什么？

原命题：∀x（x 是人 → x 是学生）

错误否定："所有人都不是学生"（∀x，x 不是学生）——这不对！

正确否定："存在一个人不是学生"（∃x，x 是人且 x 不是学生）

否定一个全称命题，不是否定结论本身，而是说"存在反例"。

4. 特称命题的否定

特称命题的否定是一个全称命题：

¬(∃x ∈ M，p(x))  ⇔  ∀x ∈ M，¬p(x)

例："有人会飞"的否定是什么？

原命题：∃x（x 是人且 x 会飞）

错误否定："有人不会飞"——这不对！

正确否定："所有人都不会飞"（∀x，x 是人 → x 不会飞）

否定一个特称命题，等于说"所有个体都不满足条件"。

📝 否定规则口诀：∀ 变 ∃，∃ 变 ∀，结论取否定

概念 判断全称命题"∀x ∈ R，x² - 2x + 1 ≥ 0"的真假。
A. 真命题
B. 假命题
C. 有时真有时假
D. 不是命题
解析：x² - 2x + 1 = (x - 1)²。对于任意实数 x，(x - 1)² ≥ 0 恒成立。所以该全称命题为 真命题。选 A。
概念 全称命题"∀x ∈ R，x² > 0"的否定是？
A. ∀x ∈ R，x² ≤ 0
B. ∃x ∈ R，x² ≤ 0
C. ∃x ∈ R，x² > 0
D. ∀x ∈ R，x² < 0
解析：根据否定规则：∀ 变 ∃，结论取否定。
原命题：∀x ∈ R，x² > 0
否定：∃x ∈ R，x² ≤ 0
实际上，x = 0 时 x² = 0 ≤ 0，所以原命题是假命题，其否定是真命题。选 B。
概念 特称命题"存在一个 x ∈ R，使得 x² + 2x + 2 = 0"的否定是？
A. 存在一个 x ∈ R，使得 x² + 2x + 2 ≠ 0
B. 对任意 x ∈ R，x² + 2x + 2 ≠ 0
C. 不存在 x ∈ R，使得 x² + 2x + 2 ≠ 0
D. 对任意 x ∈ R，x² + 2x + 2 = 0
解析：根据否定规则：∃ 变 ∀，结论取否定。
原命题：∃x ∈ R，x² + 2x + 2 = 0
否定：∀x ∈ R，x² + 2x + 2 ≠ 0
实际上 x² + 2x + 2 = (x+1)² + 1 ≥ 1，确实不可能为 0，所以原命题是假命题，其否定是真命题。选 B。

练习 5（10 分）— 综合应用

已知命题 p：∀x ∈ R，x² + 2ax + 1 > 0 是真命题，求实数 a 的取值范围。

解析：
原命题："∀x ∈ R，x² + 2ax + 1 > 0"为真，即二次函数 f(x) = x² + 2ax + 1 的图像恒在 x 轴上方。
