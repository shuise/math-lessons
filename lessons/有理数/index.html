有理数

知识名称

正数与负数、数轴、相反数与绝对值、有理数的大小比较与四则运算

定理 / 公理

  • 有理数定义： 整数和分数统称为有理数（有限小数和无限循环小数也是有理数）
  • 数轴： 规定了原点、正方向和单位长度的直线
  • 相反数： 只有符号不同的两个数互为相反数，如 5 和 −5
  • 绝对值： 数轴上表示一个数的点到原点的距离，记作 |a|
  • 有理数加法法则： 同号相加取相同符号，异号相加取绝对值大的符号并用大绝对值减小绝对值
  • 有理数乘法法则： 同号得正，异号得负，绝对值相乘
  • 负负得正： (−a) × (−b) = a × b

解释

为什么要有负数？

如果问你 3 − 5 = ? 在整数范围内，你回答不了——因为 3 不够减 5。但现实生活中有这种情况：你口袋里只有 3 元，买一根 5 元的冰棍，那你就欠老板 2 元。这个"欠 2 元"就是 −2。负数就是用来表示"不够"、"欠"、"零下"、"低于"这些概念的。

在小学我们已经认识了自然数（1、2、3……）和 0，现在把负数加进来，就形成了整数：……−3, −2, −1, 0, 1, 2, 3……再进一步，把整数和分数合在一起，就是有理数。

数轴——数字的"尺子"

画一条直线，中间标 0（原点），右边是正数（1、2、3……），左边是负数（−1、−2、−3……），再加上方向箭头。这就是数轴。每个有理数都能在数轴上找到一个唯一的位置。数轴让我们"看见"数字的大小——越往右数越大，越往左数越小。

相反数——对称的两兄弟

3 和 −3 在数轴上关于 0 对称，它们就是相反数。它们绝对值一样，符号相反。0 的相反数是它自己。

绝对值——到原点的距离

|3| = 3，|−3| = 3。绝对值只看"有多远"，不看方向。|−5| = 5，因为 −5 这个点到 0 的距离是 5 个单位。

有理数的运算

加法：同号相加，符号不变，绝对值相加。异号相加，取绝对值大的符号，用大绝对值减小绝对值。比如 (−5) + (−3) = −8；( −5) + 3 = −2；5 + (−3) = 2。

减法：减去一个数 = 加上这个数的相反数。a − b = a + (−b)。所以 5 − (−3) = 5 + 3 = 8。

乘法：同号得正，异号得负。正正得正 (3 × 2 = 6)、负负得正 [(−3) × (−2) = 6]、正负得负 [(−3) × 2 = −6]。为什么负负得正？可以这样想：负号代表"相反方向"，两次"相反"就回到原方向了。

关键概念

  • 正数： 大于 0 的数，可带"+"号（通常省略）
  • 负数： 小于 0 的数，必带"−"号
  • 有理数： 整数和分数的总称，包括有限小数和无限循环小数
  • 数轴： 有原点、正方向、单位长度的直线，每个有理数对应一个点
  • 相反数： 绝对值相等、符号相反的两个数
  • 绝对值： 数到原点的距离，永远非负
  • 科学记数法： 把一个数写成 a × 10ⁿ 的形式（1 ≤ |a| < 10）

例题

例 1：绝对值与相反数

求 −7 的相反数和绝对值；求 |−3| 的值。

解答：

第 1 步：−7 的相反数是 7（符号取反）

第 2 步：|−7| = 7（到原点的距离是 7）

第 3 步：|−3| = 3

−7 的相反数是 7，绝对值是 7；|−3| = 3

例 2：有理数加法

计算：(−8) + 5 + (−2) + 7

解答：

第 1 步：从左到右计算 → (−8) + 5 = −3

第 2 步：−3 + (−2) = −5

第 3 步：−5 + 7 = 2

结果：= 2

例 3：有理数乘法与除法

计算：(−12) × (−3) ÷ (−6)

解答：

第 1 步：先算乘法 → (−12) × (−3) = 36（同号得正）

第 2 步：36 ÷ (−6) = −6（异号得负）

结果：= −6

例 4：混合运算

计算：−2² + (−3) × [4 − (−1)]

解答：

第 1 步：先算括号内 → 4 − (−1) = 4 + 1 = 5

第 2 步：算乘方 → −2² = −4（注意：是 2² 的相反数，不是 (−2)²）

第 3 步：算乘法 → (−3) × 5 = −15

第 4 步：算加法 → −4 + (−15) = −19

结果：= −19

区分 −2² 和 (−2)²：−2² = −(2×2) = −4，而 (−2)² = (−2)×(−2) = 4。

例 5：科学记数法

把 384400000 用科学记数法表示（地球到月球的距离，单位：米）。

解答：

第 1 步：找到第一个数字 3，在它后面点小数点 → 3.844

第 2 步：数一下小数点移动了 8 位 → ×10⁸

384400000 = 3.844 × 10⁸
