有理数

知识名称

正数与负数、数轴、相反数与绝对值、有理数的四则运算

定理 / 公理

  • 有理数定义： 整数和分数统称为有理数（有限小数和无限循环小数也是有理数）
  • 数轴： 规定了原点、正方向和单位长度的直线
  • 相反数： 只有符号不同的两个数，如 5 和 −5，0 的相反数是 0
  • 绝对值： 数到原点的距离，记作 |a|。|a| ≥ 0 永远成立
  • 加法法则： 同号相加取相同符号，异号相加取绝对值较大的符号
  • 减法法则： a − b = a + (−b)，即减去一个数等于加上它的相反数
  • 乘法法则： 同号得正，异号得负，绝对值相乘
  • 除法法则： a ÷ b = a × 1/b（b ≠ 0），除以一个数等于乘以它的倒数
  • 负负得正： (−a) × (−b) = a × b

历史小故事

负数的身份——从"荒谬"到"合法"

今天我们认为负数理所当然，但在数学史上，负数经历了漫长的被接受过程。早在公元 1 世纪，中国《九章算术》就提出了"正负术"——用红色算筹表示正数、黑色算筹表示负数，这是世界上最早的负数概念。但在欧洲，直到 16 世纪，很多数学家还把负数称为"荒谬的数"。笛卡尔称负数为"假数"，因为当时的人们无法想象"比没有还少"。

真正让负数"合法化"的是日常生活的需求——温度、海拔、收支……这些实际应用让人们认识到，负数并不是"不存在"，而是与正数相反方向上的量。今天的数轴上，负数和正数对称地分布在 0 的两边，和谐又美丽。

例题

例 1：比较有理数大小

比较 −5、−1、0、3 的大小。

分析：在数轴上，越靠右的数越大。

解答：

第 1 步：画出数轴 → −5 < −1 < 0 < 3

从小到大：−5 < −1 < 0 < 3

💡 负数的"大小"和直觉相反：−5 比 −1 更小（温度 −5°C 比 −1°C 更冷）。

例 2：有理数加法

计算：(−5) + (−3) 和 (−5) + (+8)

分析：同号相加取相同符号；异号相加大减小并取绝对值大的符号。

解答：

(−5) + (−3)：同号（都是负），绝对值相加 = 5 + 3 = 8，取负号 → −8

(−5) + (+8)：异号，大减小 = 8 − 5 = 3，取绝对值大的符号（+）→ +3

💡 用数轴理解：从 −5 往右走 3 步到 −2，再走 5 步到 +3。

例 3：有理数减法——变成加法

计算：(−7) − (−5) 和 3 − (−2)

分析：减去一个数 = 加上它的相反数。

解答：

(−7) − (−5) = (−7) + (+5) = −2

3 − (−2) = 3 + (+2) = 5

结果分别是 −2 和 5

💡 口诀：减负等于加正。

例 4：有理数乘法——负负得正

计算：(−3) × (−4) 和 (−2) × 5

分析：同号相乘得正，异号相乘得负。

解答：

(−3) × (−4)：负负得正 → 3 × 4 = 12

(−2) × 5：异号得负 → −(2 × 5) = −10

结果分别是 12 和 −10

例 5：混合运算——先定符号再算绝对值

计算：(−15) ÷ (−3) × (−2)

分析：先确定结果符号（负号有几个），再算绝对值。

解答：

第 1 步：数负号个数 → (−15)÷(−3)×(−2) 中有 3 个负号 → 奇数个负号 → 结果为负

第 2 步：绝对值计算 → 15 ÷ 3 × 2 = 5 × 2 = 10

结果为 −10

💡 一个实用技巧：先数负号的个数——奇数个得负，偶数个得正。

例 6：绝对值应用

已知 |x| = 5，求 x 的值。

分析：绝对值等于 5 表示到原点距离为 5，有 2 个点——左边和右边各一个。

解答：

第 1 步：|x| = 5 表示 x 到原点的距离是 5

第 2 步：原点左侧距离 5 的点是 −5，右侧是 +5

x = 5 或 x = −5
