分式

知识名称

分式的概念与基本性质、分式的约分与通分、分式的四则运算、分式方程

定理 / 公理

  • 分式的定义： 形如 A/B，其中 A 和 B 都是整式，且 B 中含有字母（B ≠ 0）
  • 分式的基本性质： 分子和分母同时乘（或除以）同一个不为 0 的整式，分式的值不变
  • 约分： 把分子和分母的公因式约去，化成最简分式
  • 通分： 把几个异分母分式化成同分母分式
  • 分式方程： 分母中含有未知数的方程
  • 增根： 分式方程去分母化成的整式方程的根，但使原分式分母为 0

解释

分式——分数的"升级版"

在小学我们学了分数，如 2⁄3、7⁄8。现在把分母从数字换成字母——比如 2⁄x、x+1⁄x−2——这就叫分式。

分式和分数一样，分母不能为 0。2⁄x 中 x ≠ 0；x+1⁄x−2 中 x − 2 ≠ 0，即 x ≠ 2。所以分式有"自然定义域"——使分母不为 0 的所有取值。

分式的基本性质——和分数一模一样

分数有基本性质：分子分母同乘一个非零数，大小不变。1⁄2 = 2⁄4 = 3⁄6。分式也一样：x⁄2y = 3x⁄6y（分子分母同乘 3）。这意味分式也可以约分和通分，只不过现在处理的是整式而不是数字。

约分——约去公因式

x²−1⁄x²+2x+1 这个分式看起来很复杂。但 x² − 1 = (x+1)(x−1)，x² + 2x + 1 = (x+1)²，分子分母有公因式 (x+1)，约去后得 x−1⁄x+1。这就是分式的约分——和分数约分是一个道理。

分式方程——注意检验

解分式方程的标准方法是：两边同乘最简公分母，去掉分母化成整式方程，然后解这个整式方程。但有一个陷阱——增根。

因为去分母时乘了一个含字母的式子（最简公分母），这个式子可能为 0，导致产生"假解"。所以分式方程解完后必须检验：把解代入最简公分母，看是否为零。为 0 的就是增根，要舍去。

关键概念

  • 分式： 分母中含有字母的式子（分母 ≠ 0）
  • 最简公分母： 把所有分母的公因式和各自独有的因式都乘起来
  • 约分： 分子分母同时除以公因式
  • 通分： 利用分式基本性质，化成相同分母
  • 分式方程： 分母中有未知数的方程
  • 增根： 使分式分母为 0 的"假解"，必须舍去

例题

例 1：分式有意义的条件

x 取何值时，分式 x+2⁄x−3 有意义？

解答：

第 1 步：分母不能为 0 → x − 3 ≠ 0

第 2 步：x ≠ 3

x ≠ 3 时，分式有意义

例 2：分式约分

约分：6x²y⁄9xy²

解答：

第 1 步：系数约分 → 6 和 9 的最大公因数是 3 → 6÷3=2, 9÷3=3

第 2 步：字母部分 → x² ÷ x = x, y ÷ y² = 1/y

第 3 步：合并 → 2x / 3y

结果：2x⁄3y

例 3：分式加减

计算：3⁄x + 2⁄x+1

解答：

第 1 步：找最简公分母 → x(x+1)

第 2 步：通分 → 3(x+1)⁄x(x+1) + 2x⁄x(x+1)

第 3 步：分母不变，分子相加 → 3(x+1) + 2x⁄x(x+1)

第 4 步：化简分子 → 3x + 3 + 2x = 5x + 3

结果：5x+3⁄x(x+1)

例 4：分式方程

解方程：2⁄x = 3⁄x+1

解答：

第 1 步：找最简公分母 → x(x+1)

第 2 步：两边同乘 x(x+1) → 2(x+1) = 3x

第 3 步：展开 → 2x + 2 = 3x

第 4 步：移项 → 2 = 3x − 2x → x = 2

第 5 步：检验 → x = 2 时，原分母 x = 2 ≠ 0, x+1 = 3 ≠ 0，所以 x = 2 是原方程的解

x = 2

例 5：增根问题

解方程：1⁄x−1 = 2⁄x²−1

解答：

第 1 步：分母因式分解 → x² − 1 = (x+1)(x−1)，最简公分母 (x+1)(x−1)

第 2 步：两边同乘 (x+1)(x−1) → (x+1) = 2

第 3 步：解得 x = 1

第 4 步：检验 → x = 1 时，原分母 x − 1 = 0

x = 1 是增根，原方程无解

重要：分式方程一定要检验！增根不是真正的解。
