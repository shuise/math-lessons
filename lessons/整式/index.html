整式

知识名称

代数式与整式的概念、整式的加减乘除、幂的运算、乘法公式、因式分解

定理 / 公理

  • 幂的运算法则： aᵐ × aⁿ = aᵐ⁺ⁿ；(aᵐ)ⁿ = aᵐⁿ；(ab)ⁿ = aⁿbⁿ；aᵐ ÷ aⁿ = aᵐ⁻ⁿ（a≠0）
  • 平方差公式： (a + b)(a − b) = a² − b²
  • 完全平方公式： (a ± b)² = a² ± 2ab + b²
  • 合并同类项： 把系数相加，字母和指数不变
  • 去括号法则： 括号前是"+"，去括号不变号；括号前是"−"，去括号全变号

解释

从数字到字母——代数式的诞生

小学时我们说"3 + 5 = 8"，这是具体数字的计算。到了初中，我们说"x + 5 = 8"——x 可以代表任何数。用字母代替数字，就是代数的开始。

用运算符号把数和字母连接起来的式子叫代数式。比如 3x + 2y − 5、a² + b²、2(x + 1)。其中只涉及加、减、乘、除、乘方运算，且分母不含字母的代数式叫整式。

单项式与多项式

整式分为两类：单项式和多项式。

  • 单项式：数字和字母的乘积，如 3x²、−5ab、7（单独一个数也是单项式）。3x² 中，3 叫系数，x² 中 x 的指数 2 叫次数。
  • 多项式：多个单项式的和，如 3x² + 2x − 1。每个单项式叫项，次数最高的项的次数就是多项式的次数。

合并同类项——物以类聚

3x² + 5x − 2x² + 3x = (3−2)x² + (5+3)x = x² + 8x。只有字母部分完全一样的项才能合并（同样的字母、同样的指数），这就是合并同类项。

幂的运算——指数王国

x² × x³ = (x·x) × (x·x·x) = x⁵（指数相加）。反过来，x⁵ ÷ x² = (x·x·x·x·x) ÷ (x·x) = x³（指数相减）。这些规则看起来自然，关键是要理解幂的本质——重复相乘。

乘法公式——计算加速器

(a + b)(a − b) = a² − b² 这个公式叫平方差公式。为什么？(a + b)(a − b) = a² − ab + ab − b² = a² − b²，中间两项正好抵消。

(a + b)² = a² + 2ab + b² 叫完全平方公式。(a + b)² 就是 (a + b)(a + b)，展开后 a² + ab + ab + b² = a² + 2ab + b²。

关键概念

  • 代数式： 用运算符号连接数和字母的式子
  • 整式： 代数式中，分母不含字母的（单项式和多项式）
  • 单项式： 数字和字母的乘积，如 3x²y
  • 多项式： 多个单项式的和，如 2x² − 3x + 5
  • 同类项： 字母部分完全相同的项，可以合并
  • 幂的运算： 同底数幂相乘指数相加，相除指数相减
  • 乘法公式： (a + b)(a − b) = a² − b²；(a ± b)² = a² ± 2ab + b²

例题

例 1：合并同类项

化简：4x² − 3x + 7 + 2x² + 5x − 2

解答：

第 1 步：找同类项 → x²项（4x² 和 2x²）、x 项（−3x 和 5x）、常数项（7 和 −2）

第 2 步：合并 → (4 + 2)x² + (−3 + 5)x + (7 − 2)

第 3 步：计算 → 6x² + 2x + 5

结果：6x² + 2x + 5

例 2：幂的运算

计算：(2x²)³ × (−x³)²

解答：

第 1 步：(2x²)³ = 2³ × (x²)³ = 8 × x⁶ = 8x⁶（积的乘方和幂的乘方）

第 2 步：(−x³)² = (−1)² × x⁶ = 1 × x⁶ = x⁶

第 3 步：8x⁶ × x⁶ = 8x¹²

结果：8x¹²

例 3：平方差公式

计算：(2x + 3)(2x − 3)

解答：

第 1 步：公式 (a + b)(a − b) = a² − b²，这里 a = 2x, b = 3

第 2 步：代入 → (2x)² − 3²

第 3 步：计算 → 4x² − 9

结果：4x² − 9

例 4：完全平方公式

计算：(3y − 2)²

解答：

第 1 步：公式 (a − b)² = a² − 2ab + b²，a = 3y, b = 2

第 2 步：a² = (3y)² = 9y²

第 3 步：−2ab = −2 × 3y × 2 = −12y

第 4 步：b² = 2² = 4

结果：9y² − 12y + 4

例 5：整式除法

计算：(6x³ + 8x²) ÷ 2x

解答：

第 1 步：把每一项分别除以 2x → 6x³ ÷ 2x + 8x² ÷ 2x

第 2 步：6x³ ÷ 2x = 3x²（系数相除，指数相减 3−1=2）

第 3 步：8x² ÷ 2x = 4x

结果：3x² + 4x
