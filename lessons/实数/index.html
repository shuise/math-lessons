实数

知识名称

算术平方根、平方根、立方根、无理数的概念、实数的分类

定理 / 公理

  • 算术平方根： 如果一个正数 x 的平方等于 a，即 x² = a，那么 x 叫 a 的算术平方根，记作 √a（a ≥ 0）
  • 平方根： 如果一个数 x 的平方等于 a，即 x² = a，那么 x 叫 a 的平方根，记作 ±√a
  • 立方根： 如果一个数 x 的立方等于 a，即 x³ = a，那么 x 叫 a 的立方根，记作 ³√a
  • 无理数： 无限不循环小数，如 √2、π、e 等
  • 实数： 有理数和无理数的总称
  • 非负数性质： √a ≥ 0（a ≥ 0），几个非负数之和为 0 则每个非负数都为 0

解释

平方根——什么数的平方等于它？

3² = 9，我们说 9 的平方根是 ±3（因为 (−3)² 也等于 9）。但算术平方根只取非负的那个：√9 = 3。

注意：负数没有平方根（在实数范围内）。因为任何数的平方都不可能是负数。但负数有立方根——³√(−8) = −2，因为 (−2)³ = −8。

无理数——"讲不清理还乱"的数

初中数学最大的"爆炸性新闻"就是：世界上有一种数，它不能写成分数形式！√2 就是其中之一。√2 ≈ 1.41421356……小数位无限而且不循环。这样的数就叫无理数。

√2 是怎么发现的？一个边长 1 的正方形，对角线长度 = √(1² + 1²) = √2。古人原本相信"所有数都能用分数表示"，但 √2 打破了这个信念——它不能写成 p⁄q 的形式。这个发现曾经让毕达哥拉斯学派陷入恐慌。

常见的无理数

  • √2、√3、√5……开不尽的平方根
  • π ≈ 3.1415926535……（圆的周长与直径之比）
  • e ≈ 2.7182818284……（自然对数的底数）
  • 0.1010010001……（有规律但不循环的小数）

实数系——数字的完整"家族"

把所有有理数和无理数放在一起，就是实数。每个实数都对应数轴上的一个点，而且数轴上的每个点也都对应一个实数——这就是"实数"这个名字的由来，意味着"实实在在的数"。

实数分类图：
实数 = 有理数（整数 + 有限小数 + 无限循环小数）∪ 无理数（无限不循环小数）

关键概念

  • 算术平方根 √a： 非负数 a 的非负平方根
  • 平方根 ±√a： 两个互为相反数的根（a ≥ 0）
  • 立方根 ³√a： 任何实数都有唯一立方根
  • 无理数： 无限不循环小数，不能写成分数
  • 实数： 有理数 + 无理数，填满整个数轴
  • 开方： 乘方的逆运算，求平方根或立方根

例题

例 1：求平方根和算术平方根

求 64 的平方根和算术平方根。

解答：

第 1 步：问自己——什么数的平方等于 64？→ 8² = 64, (−8)² = 64

第 2 步：平方根有两个 → ±√64 = ±8

第 3 步：算术平方根取正的那个 → √64 = 8

平方根是 ±8，算术平方根是 8

例 2：求立方根

求 −27 的立方根。

解答：

第 1 步：问自己——什么数的立方等于 −27？

第 2 步：(−3)³ = (−3)×(−3)×(−3) = −27

³√(−27) = −3

例 3：化简含根号的式子

计算：√12 + √27 − √48

解答：

第 1 步：把每个根号化简 → √12 = √(4×3) = 2√3

第 2 步：√27 = √(9×3) = 3√3

第 3 步：√48 = √(16×3) = 4√3

第 4 步：合并 → 2√3 + 3√3 − 4√3 = (2+3−4)√3 = √3

结果：= √3

化简根号：把根号内的数分解成平方因数 × 其他，平方因数开出来。

例 4：判断无理数

下列各数哪些是有理数？哪些是无理数？
3.14, 22⁄7, √5, π, 0.333……, √9

解答：

有理数（可写成分数形式）：3.14 = 314⁄100, 22⁄7 本身就是分数, 0.333… = 1⁄3, √9 = 3（整数）

无理数（无限不循环）：√5（≈2.236…开不尽）, π（≈3.14159…无限不循环）

有理数：3.14, 22⁄7, 0.333…, √9；无理数：√5, π
