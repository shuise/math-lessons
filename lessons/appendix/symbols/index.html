数学符号速查表

本课件体系中出现的主要数学符号，按类别分组整理。每个符号给出其中文名称、英文名称及含义说明，方便快速查阅。

1.1 集合论符号

符号中文名称英文名称含义说明
∈属于belongs to元素属于某个集合，如 a ∈ A
∉不属于does not belong to元素不属于某个集合

⊇包含supersetA ⊇ B 表示 B ⊆ A

∩交集intersectionA ∩ B 表示同时属于 A 和 B 的元素
∅空集empty set不含任何元素的集合
∘补集complement∘UA 表示 U 中不在 A 中的元素
⊕对称差symmetric differenceA ⊕ B = (A-B) ∪ (B-A)
ℕ自然数集natural numbersℕ = {0, 1, 2, 3, ...}
ℤ整数集integersℤ = {..., -2, -1, 0, 1, 2, ...}
ℚ有理数集rational numbers可表示为 p/q (q≠0) 的数
