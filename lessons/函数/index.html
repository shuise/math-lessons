函数 — 从概念到应用

涵盖了函数的概念、分析工具、常见函数类型、指数/对数/三角以及综合应用。

一、知识名称

函数——描述变量之间依赖关系的数学工具。

无论是自然现象（温度随时间变化）、经济活动（利润随销量变化）还是日常经验（路程随速度变化），只要一个量随另一个量变化，就可以用函数来描述。

一句话记忆：函数就是一台"输入-输出"机器——你给它一个输入值，它按照规则产生一个输出值。

本课涵盖以下函数类型：二次函数、幂函数、指数函数、对数函数和三角函数。

二、定理 / 公理

2.1 函数的定义（三要素）

函数：设 A、B 是两个非空数集，按照某种对应关系 f，对于 A 中的任意一个数 x，在 B 中都有唯一确定的数 f(x) 和它对应，则称 f 为从 A 到 B 的函数。

三要素：定义域（A）、值域（{f(x) | x ∈ A}）、对应关系（f）

2.2 基本不等式

对于任意正数 a、b，有：√(ab) ≤ (a + b)/2

当且仅当 a = b 时取等号。

2.3 指数与对数的运算性质

指数运算：

am · an = am+n

(am)n = amn

(ab)n = anbn

对数运算：

loga(MN) = logaM + logaN

loga(M/N) = logaM − logaN

loga(Mn) = n · logaM

换底公式：logab = logcb / logca

2.4 三角恒等式

同角关系：sin2α + cos2α = 1     tanα = sinα / cosα

两角和：sin(α ± β) = sinα cosβ ± cosα sinβ

倍角：sin 2α = 2 sinα cosα     cos 2α = cos2α − sin2α

2.5 单调性判定定理

设函数 f(x) 在区间 I 上有定义，对任意 x1 < x2 ∈ I：

若 f(x1) < f(x2)，则 f 在 I 上单调递增

若 f(x1) > f(x2)，则 f 在 I 上单调递减

2.6 奇偶性判定

若定义域关于原点对称：

f(−x) = f(x) ⇒ 偶函数（图像关于 y 轴对称）

f(−x) = −f(x) ⇒ 奇函数（图像关于原点对称）

五、知识点的用途

二次函数

  • 抛射运动：篮球投出的轨迹、烟花弹的飞行路径都是抛物线
  • 经济模型：利润 = −ax2 + bx + c 的形式，求最大利润
  • 面积优化：固定周长时，求最大面积的矩形

指数与对数函数

  • 人口增长：初期呈指数增长 N(t) = N0 · 2t/T
  • 复利计算：A = P(1 + r/n)nt，利息产生利息
  • 放射性衰变：半衰期模型 m(t) = m0 · (1/2)t/T
  • 地震震级：里氏震级是对数尺度，M = log(A / A0)
  • 酸碱度：pH = −log[H+]

三角函数

  • 简谐运动：弹簧振子的位移 y = A sin(ωt + φ)
  • 交流电：电压 V(t) = V0 sin(2πft)
  • 声波：声音的波形是不同频率三角函数的叠加
  • 潮汐：海平面周期性涨落可以用三角函数拟合

六、历史小故事

“函数”的诞生与演变

1698 年，德国数学家莱布尼茨在一封信里首次使用了 "function" 这个词。当时他指的是一条曲线上变化的几何量。

1748 年，瑞士数学家欧拉在他著名的《无穷小分析引论》中，把函数定义为"由变量和常数构成的解析表达式"。这是最早的系统化定义。

1837 年，德国数学家狄利克雷给出了接近现代的定义："如果对于某个区间上的每个 x 值，都有一个唯一的 y 值与之对应，则 y 称为 x 的函数。"

有趣的是，狄利克雷还构造了一个当时让人非常难以接受的函数：当 x 是有理数时，f(x) = 1；当 x 是无理数时，f(x) = 0。这个函数无法用任何公式写出，但完全符合函数的定义。它告诉人们：函数的概念远比"公式"更广泛。

对数的发明与天文学

16 世纪末，天文学家第谷积累了海量天文数据，他的学生开普勒需要做大量的乘除运算。那时没有计算器，一次乘法需要耗时数分钟，还容易出错。

苏格兰数学家纳皮尔花了 20 年时间，在 1614 年发表了对数。它的核心思想是把乘法变成加法：log(ab) = log a + log b。有了对数表，天文学家把几年的计算量缩短成了几周。

拉普拉斯后来感叹：“对数的发明，把天文学家的寿命延长了一倍！”

弧度制与π

为什么数学家用弧度而不是角度来度量角？因为弧度是自然的：1 弧度对应的是"半径长的弧"。

使用弧度制时，许多公式变得简洁优美。例如，sin x 的导数就是 cos x（使用角度制时，sin x 的导数是 π/180 · cos x，多了一个难看的系数）。

数学家的选择标准是：哪个公式更简单，就用哪个。

七、例题

例 1（二次函数与基本不等式）

已知 x > 0，求 y = x + 1/x 的最小值。

分析：两个正数之和的最小值，想到基本不等式。

解：由基本不等式：x + 1/x ≥ 2√(x · 1/x) = 2

当且仅当 x = 1/x，即 x = 1 时取等号。

所以 y 的最小值为 2。

例 2（幂函数）

比较 (0.5)0.4 和 (0.5)0.6 的大小。

分析：底数相同（0.5），考察指数函数 y = (0.5)x 的单调性。

解：y = (0.5)x 中 0 < 0.5 < 1，所以函数在 R 上单调递减。

因为 0.4 < 0.6，所以 (0.5)0.4 > (0.5)0.6。

(0.5)0.4 > (0.5)0.6

技巧：比较幂的大小，可以先看底数是否相同。底数相同⇒用指数函数单调性；指数相同⇒用幂函数单调性。

例 3（指数与对数）

计算 log28 + log2(1/2) 的值。

解：log28 = log223 = 3

log2(1/2) = log22−1 = −1

所以 log28 + log2(1/2) = 3 + (−1) = 2

结果为 2。

例 4（三角函数）

已知 sinα = 3/5，α 是锐角，求 cosα 和 tanα 的值。

分析：利用同角三角函数关系 sin2α + cos2α = 1。

解：cos2α = 1 − sin2α = 1 − 9/25 = 16/25

因为 α 是锐角，cosα > 0，所以 cosα = 4/5

tanα = sinα / cosα = (3/5) / (4/5) = 3/4

cosα = 4/5，tanα = 3/4。

例 5（函数图像变换）

函数 y = 2 sin(3x + π/4) 的振幅、周期和初相分别是多少？

解：对照标准形式 y = A sin(ωx + φ)

• 振幅 A = 2

• 角频率 ω = 3，周期 T = 2π/|ω| = 2π/3

• 初相 φ = π/4

振幅为 2，周期为 2π/3，初相为 π/4。
