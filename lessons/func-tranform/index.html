性质对比分析

原函数 y = x²

变换后 y = (x−h)²

水平平移：y = f(x) → y = f(x−h)。当 h > 0 时图像向右平移 h 个单位；h < 0 时向左平移 |h| 个单位。
性质变化：定义域整体平移 h，值域不变；单调区间平移 h；对称轴平移 h；奇偶性一般被破坏（除非 h=0）。
