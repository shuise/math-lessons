分式

知识名称

分式的概念与基本性质、分式的约分与通分、分式的四则运算、分式方程

定理 / 公理

  • 分式定义： 形如 A/B，其中 A、B 是整式，且 B 中含有字母（B ≠ 0）
  • 分式有意义条件： 分母 ≠ 0
  • 分式的值为 0 条件： 分子 = 0 且分母 ≠ 0
  • 分式基本性质： 分子分母同时乘（或除以）同一个不为 0 的整式，分值不变
  • 约分： 分子分母的公因式约去，化成最简分式
  • 通分： 用各分母的最简公分母统一分母
  • 分式乘法： A/B × C/D = AC/BD（分子乘分子，分母乘分母）
  • 分式除法： A/B ÷ C/D = A/B × D/C（除以一个分式等于乘以它的倒数）
  • 分式方程解法： 去分母（两边同乘最简公分母）→ 解整式方程 → 检验（排除增根）

历史小故事

分式与分数——表兄弟的关系

分式（分子分母是整式）和分数（分子分母是整数）非常相似。事实上，分数就是分式的"特例"——当字母取具体数字时，分式就变成了分数。分数的一切运算规则（约分、通分、加减乘除）在分式中都适用，只是把"数字"换成了"整式"。所以，如果你已经掌握了分数的运算，分式就很好理解——只不过在分母中多了一些字母，别忘了检查分母不为 0！

例题

例 1：分式有意义条件

当 x 取何值时，分式 2x/x−3 有意义？

分析：分式有意义要求分母 ≠ 0。

解答：

第 1 步：令分母 x − 3 = 0

第 2 步：x = 3

第 3 步：所以当 x = 3 时分式无意义，x ≠ 3 时分式有意义

x ≠ 3

例 2：分式值为 0

当 x 取何值时，分式 x²−4/x+2 的值为 0？

分析：分子 = 0 且分母 ≠ 0。

解答：

第 1 步：分子 = 0 → x² − 4 = 0 → x = ±2

第 2 步：检查分母 → x = 2 时，分母 2+2=4 ≠ 0，可取；x = −2 时，分母 −2+2=0，舍去

x = 2

💡 分子为 0 只是必要条件，还必须保证分母不为 0。

例 3：约分

约分：6x³y²/9x²y⁴

分析：分子分母同除以它们的公因式。

解答：

第 1 步：系数约分 → 6/9 = 2/3

第 2 步：字母约分 → x³/x² = x，y²/y⁴ = 1/y²

第 3 步：合并 → 2x / 3y²

6x³y²/9x²y⁴ = 2x/3y²

例 4：分式加减

计算：3/x + 2/x²

分析：异分母分式相加，先通分。最简公分母是 x²。

解答：

第 1 步：通分 → 3x/x² + 2/x²

第 2 步：同分母相加 → (3x + 2)/x²

3/x + 2/x² = 3x+2/x²

例 5：分式方程——检验增根

解方程：2/x−1 = 3/x

分析：去分母后解整式方程，最后一定要检验。

解答：

第 1 步：两边同乘 x(x−1) → 2x = 3(x−1)

第 2 步：2x = 3x − 3 → x = 3

第 3 步：检验 → 代入分母 x = 3，x−1 = 2，都不为 0

x = 3

💡 检验是分式方程的关键——忽视检验可能得到"增根"（使分母为 0 的假解）。

例 6：分式应用题——工作效率

甲单独完成一项工程需要 x 天，乙需要 (x+3) 天。两人合作 2 天完成了工程的一半，求 x。

分析：甲每天完成 1/x，乙每天完成 1/x+3。两人 2 天完成一半。

解答：

第 1 步：列方程 → 2(1/x + 1/x+3) = 1/2

第 2 步：两边乘 2x(x+3) → 4(x+3) + 4x = x(x+3)

第 3 步：4x + 12 + 4x = x² + 3x

第 4 步：8x + 12 = x² + 3x → x² − 5x − 12 = 0

第 5 步：解得 x = 分-3（负值舍去）或 x = 4

第 6 步：检验 → x = 4，分母都不为 0

甲单独需要 4 天，乙需要 7 天
