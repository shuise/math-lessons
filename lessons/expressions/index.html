整式

知识名称

代数式与整式的概念、整式的加减乘除、幂的运算、乘法公式、因式分解

定理 / 公理

  • 幂的运算法则：
    • aᵐ × aⁿ = aᵐ⁺ⁿ（同底数幂相乘，指数相加）
    • (aᵐ)ⁿ = aᵐⁿ（幂的乘方，指数相乘）
    • (ab)ⁿ = aⁿbⁿ（积的乘方，分别乘方）
    • aᵐ ÷ aⁿ = aᵐ⁻ⁿ（a≠0，同底数幂相除，指数相减）
    • a⁰ = 1（a≠0，任何非零数的 0 次方等于 1）
  • 平方差公式： (a + b)(a − b) = a² − b²
  • 完全平方公式： (a ± b)² = a² ± 2ab + b²
  • 合并同类项： 系数相加，字母和指数不变
  • 去括号法则： 括号前是"+"不变号，是"−"全变号
  • 单项式×单项式： 系数相乘，字母分别按幂的运算法则乘
  • 提公因式法： 提取各项中共有的因式

历史小故事

乘法公式的妙用——印度数学家拉马努金的故事

印度天才数学家拉马努金有一个著名故事。有一次，他的老师哈代乘出租车去医院看望他。哈代说："我乘坐的出租车号是 1729，这个数没什么意思。"拉马努金立即回答道："不，这是一个非常有趣的数字——它是可以用两种不同方式表示为两个立方数之和的最小正整数：1729 = 1³ + 12³ = 9³ + 10³。"

乘法公式 (a+b)(a−b) = a² − b² 在速算中也很有用：比如 102 × 98 = (100+2)(100−2) = 10000 − 4 = 9996。掌握了这些公式，计算可以变得又快又有趣！

例题

例 1：合并同类项

化简：3x² + 5x − 2x² + 3x − 7

分析：同类项的系数相加，字母和指数不变。

解答：

第 1 步：找同类项 → x² 项：3x² 和 −2x²；x 项：5x 和 3x

第 2 步：合并 x² 项 → 3x² − 2x² = x²

第 3 步：合并 x 项 → 5x + 3x = 8x

第 4 步：常数项 −7 不变

结果为 x² + 8x − 7

例 2：幂的运算

计算：a³ × a⁵, (x³)², (2ab²)³

解答：

a³ × a⁵ = a³⁺⁵ = a⁸

(x³)² = x³ˣ² = x⁶

(2ab²)³ = 2³ × a³ × (b²)³ = 8a³b⁶

💡 先分别处理系数和字母，再按幂的运算法则计算。

例 3：平方差公式

计算：(3x + 2)(3x − 2)

分析：符合 (a+b)(a−b) = a² − b² 的形式，a = 3x，b = 2。

解答：

(3x + 2)(3x − 2) = (3x)² − 2² = 9x² − 4

结果为 9x² − 4

💡 运用平方差公式的关键：找到"相同的项"和"相反的项"。

例 4：完全平方公式

计算：(2x + 3)²

分析：符合 (a+b)² = a² + 2ab + b²，a = 2x，b = 3。

解答：

(2x + 3)² = (2x)² + 2 × (2x) × 3 + 3²

= 4x² + 12x + 9

结果为 4x² + 12x + 9

💡 口诀：首平方，末平方，两倍首末在中央。

例 5：提公因式法

因式分解：6x²y + 9xy²

分析：先找公因式——系数的最大公因数和每个字母的最低次幂。

解答：

第 1 步：系数 GCF(6,9) = 3；字母公共部分 xy

第 2 步：公因式 = 3xy

第 3 步：6x²y + 9xy² = 3xy(2x + 3y)

6x²y + 9xy² = 3xy(2x + 3y)

💡 检验：用乘法展开 3xy(2x + 3y) = 6x²y + 9xy²，和原式相同。

例 6：整式乘法——面积问题

一个长方形长 (x + 5) 米，宽 (x + 2) 米，求它的面积。

分析：面积 = 长 × 宽，用多项式乘法计算。

解答：

第 1 步：面积 = (x + 5)(x + 2)

第 2 步：逐项相乘 → x·x + x·2 + 5·x + 5·2

第 3 步：= x² + 2x + 5x + 10

第 4 步：合并同类项 → x² + 7x + 10

面积为 (x² + 7x + 10) 平方米
