同角三角函数关系

sin²α + cos²α = 1　·　tan α = sin α / cos α（cos α ≠ 0）

1 + tan²α = 1 / cos²α

诱导公式（奇变偶不变，符号看象限）

sin(−α) = −sin α　cos(−α) = cos α　sin(π−α) = sin α　cos(π−α) = −cos α

sin(π+α) = −sin α　cos(π+α) = −cos α　sin(π/2−α) = cos α　cos(π/2−α) = sin α

两角和与差

sin(α±β) = sinα·cosβ ± cosα·sinβ　cos(α±β) = cosα·cosβ ∓ sinα·sinβ

tan(α±β) = (tanα±tanβ) / (1∓tanα·tanβ)（各正切有定义且分母不为 0）

二倍角公式

sin 2α = 2 sinα·cosα　tan 2α = 2 tanα / (1−tan²α)

cos 2α = cos²α − sin²α = 2cos²α − 1 = 1 − 2sin²α

辅助角公式

a·sin x + b·cos x = √(a²+b²) · sin(x + φ)

函数基本性质

y = sin x：奇函数，周期 2π，值域 [−1, 1]　

y = cos x：偶函数，周期 2π，值域 [−1, 1]

y = tan x：奇函数，周期 π，定义域 x ≠ π/2 + kπ
