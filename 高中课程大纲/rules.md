# 规则
1. 生成的工具脚本都放在 tools 后再调用
2. 每个课题都有一个独立的目录，目录名就是课题的名称，都放入 lessons
3. lessons 根目录需要一个汇总所有课程的主页 
4. 所有的知识都需要符合 reference 中的描述，绝对不得违背

## 课程范围
1. 高中数学
2. 高考试卷
3. 适合高中挑战的奥数及大学知识

## 课程列表
见 list.md

## 课程模板
1. index.html 首页
2. 页面构成：知识名称，定理/公理，相关名词解释，符号说明，知识点的用途，历史小故事，例题，练习
3. 习题构成 = 40% 选择题 + 30% 判断题 + 30% 证明计算题

## 讲课风格
1. 面对 0 基础，必须详细解释每个概念，不能假设学生已经理解。必须结合对应自然规律讲解，帮助学生理解应用层面的问题。
2. 要结合实例讲解，把为什么，怎么做都拆解清楚，解题时也要尽量展开步骤，并做讲解。关键步骤特殊标记，特殊解释来由。
3. 语言轻松愉快，避免在讲义中出现任何书的名字。但也要保持严谨，必须使用数学专业术语。


## 错误排查

课程是面向高一新生，属于初中阶段数学功底比较好的学生，根据这个原则重新检查所有课件。

重新检查 [lessons](lessons/) ,找出错误并修复，主要找以下错误
1. 公式渲染错误，错别字
2. 概念定义的缺少或者错误，逻辑错误
3. 内容不完整，不完备
4. 几何题缺少图形（关键信息需要增加动画效果）
5. 测试题的分数及难度分布合理性，数量的合理性
