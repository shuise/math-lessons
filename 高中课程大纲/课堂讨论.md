## 2026-08-03 讨论记录

### 讨论一：德摩根定律与反证法

**学生**：未指定

**讨论问题**：
为什么只需要一个反例，就能推翻"所有……都……"这样的全称命题？

**分析过程**：
1. **翻译成符号语言**
   - 全称命题 P："∀x ∈ M，p(x) 成立"（集合 M 中所有元素都满足条件）
   - 反例 x₀：x₀ ∈ M，但 p(x₀) 不成立，即 ¬p(x₀) 为真
2. **德摩根定律的量化版本**
   - ¬(∀x，p(x)) ⇔ ∃x，¬p(x)
   - 左边 = "所有都成立"被否定（命题 P 为假）；右边 = "存在一个不成立"
   - 二者逻辑等价：要说明 P 为假，只需找到那个 x₀
3. **直观理解**
   - "所有"是对每个个体的逐一断言，像一道"通杀"检查
   - 只要有一个个体不合格，检查就整体失败，无需再检查其余个体
   - 例：断言"班里所有同学都参加了运动会"——发现一个没参加，断言立刻为假
4. **为什么"一个"就够**
   - 全称命题的结构是"∀（任意）"，其否定（德摩根）恰好是"∃（存在）不成立"
   - 一个反例直接命中 ∃¬，与"证明特称命题只需一个正例"恰好对称
5. **与反证法的联系**
   - 反证法第一步"假设结论的反面成立"，通常就是假设反例存在
   - 例：证明"√2 是无理数"（即 ∀p, q ∈ N*，√2 ≠ p/q），反证法假设 √2 = p/q（p、q 互质）——即假设反例存在——导出矛盾，从而反例不存在，原命题成立
   - "找反例推翻命题"与"假设反例存在并导出矛盾"本质同源，只是方向相反

**一句话总结**：全称命题的否定（德摩根量化版 ¬∀ ⇔ ∃¬）就是"存在一个不成立"，所以一个反例足以推翻整个全称命题；反证法则反过来——先假设反例存在，再证明它不可能。

## 2026-07-28 讨论记录

### 讨论一：指数函数 y = aˣ 中为什么 a > 0 且 a ≠ 1

**学生**：未指定

**讨论问题**：
对指数函数 y = aˣ (a > 0, a ≠ 1)，为什么底数 a 必须大于 0 且不等于 1？

**结论**：
1. **a > 0**：保证对任意实数 x，aˣ 都有唯一的实数值定义
   - a = 0：当 x ≤ 0 时 0⁻¹ = 1/0 无意义
   - a < 0：当 x 为非整数时（如 x = ½），结果为虚数，不在实数范围内
   - a > 0：对任意 x∈R，aˣ 有唯一确定的实数值
2. **a ≠ 1**：保证函数不是常数
   - a = 1：1ˣ ≡ 1，变为常数函数，图像是水平直线
   - a ≠ 1：a > 1 时单调递增，0 < a < 1 时单调递减，具备指数函数的典型性质

**一句话总结**：a > 0 保证有定义，a ≠ 1 保证不是常数。

### 讨论二：y = 1 是周期函数吗？

**学生**：未指定

**讨论问题**：
常数函数 y = 1 是否属于周期函数？

**结论**：
- 从定义出发：存在非零常数 T 使得 f(x+T) = f(x) 对任意 x 成立
- y = 1 满足定义：对任意 T ≠ 0，都有 1 = 1，因此任意非零实数都是它的周期
- 所以 y = 1 **是周期函数**，但它没有最小正周期（不存在最小的正数）
- 属于"过于平凡所以一般不被当作典型周期函数讨论"的特例
- 高中阶段讨论周期性时通常默认排除常数函数

### 讨论三：反函数存在条件的深入理解

**学生**：未指定

**讨论问题**：
"一个函数有反函数的充要条件是它在定义域内是一一映射（单射 + 满射）"——如何更细致地理解这句话？

**结论**：
1. **反函数的本质**：已知输出 y，找回唯一的输入 x。即求 f 的逆映射。
2. **单射（一对一）**：x₁ ≠ x₂ ⇒ f(x₁) ≠ f(x₂)
   - 保证不同的输入必然产生不同的输出
   - 避免出现"一个 y 对应多个 x"的情况（如 f(x)=x² 在 R 上不是单射）
   - 课堂例子：f(x)=x² 限制定义域为 x≥0 后变成单射，反函数为 f⁻¹(y)=√y
3. **满射（映上）**：值域 = 陪域
   - 保证值域中每个 y 都能找到某个 x 与之对应
   - 指数函数 y=2ˣ 的值域为 (0,+∞)，如果把陪域设为 R 则不满射；把陪域缩为 (0,+∞) 则满射
4. **高中阶段的简化理解**：
   - 单调函数一定有反函数（单调 ⇒ 单射）
   - 反函数的定义域 = 原函数的值域（自动满足满射条件）
   - 因此做题时只需判断函数是否严格单调
