# 谚语与名句中的数学逻辑

汇总知识库中隐含数学逻辑的谚语、名句，按逻辑类型分类。可用于逻辑思维教学素材。

## 一、条件与必要条件

| 谚语 | 隐含逻辑 |
|------|----------|
| "皮之不存，毛将焉附" | 必要条件：皮是毛的前提，p→q，逆否等价 |
| "覆巢之下，安有完卵" | 必要条件：整体被破坏，个体必受影响 |
| "不入虎穴，焉得虎子" | 必要条件：不冒风险就无法获得结果 |
| "人无远虑，必有近忧" | 条件命题：无远虑 → 近忧 |
| "知己知彼，百战不殆" | 充分条件：知己且知彼 → 百战不殆 |
| "学而不思则罔，思而不学则殆" | 两个必要条件缺一不可（与逻辑） |

## 二、归谬与反证

| 谚语 | 隐含逻辑 |
|------|----------|
| "自相矛盾" | 逻辑矛盾：同时主张 p 与 ¬p |
| "此地无银三百两" | 欲盖弥彰，反证法思维 |
| "城门失火，殃及池鱼" | 因果链的传递（演绎推理） |
| "覆水难收" | 沉没成本不可逆 |
| "塞翁失马，焉知非福" | 否定命题未必为假，信息不完备 |

## 三、集合与分类

| 谚语 | 隐含逻辑 |
|------|----------|
| "物以类聚，人以群分" | 分类与聚类 |
| "白马非马"（公孙龙） | 集合与元素不同层次（元素 ≠ 集合） |
| "挂羊头卖狗肉" | 名义分类与实际归属不一致 |
| "五十步笑百步" | 同类比较，相对量的差异 |

## 四、博弈与选择

| 谚语 | 隐含逻辑 |
|------|----------|
| "鹬蚌相争，渔翁得利" | 囚徒困境：非合作博弈两败俱伤 |
| "三个和尚没水喝" | 搭便车问题、边际激励失效 |
| "三个臭皮匠，顶个诸葛亮" | 与上面对立——群体决策能否奏效取决于结构 |
| "宁为鸡头，不为凤尾" | 偏好排序，非传递性偏好 |
| "两害相权取其轻" | 决策：比较期望损失 |

## 五、概率与统计

| 谚语 | 隐含逻辑 |
|------|----------|
| "不怕一万，就怕万一" | 小概率事件也不能忽略（尾部风险） |
| "天上不会掉馅饼" | 概率为 0 的期望 |
| "天下没有免费的午餐" | 机会成本恒存在（[[经济学的思维方式]]） |
| "祸不单行" | 常常是确认偏误/记忆偏差的错觉 |

## 六、极限与累积

| 谚语 | 隐含逻辑 |
|------|----------|
| "一尺之棰，日取其半，万世不竭"（庄子） | 无限细分、极限概念 |
| "不积跬步，无以至千里" | 累积求和（级数收敛） |
| "九层之台，起于累土" | 递归与累积 |
| "锲而不舍，金石可镂" | 重复操作、迭代 |
| "差之毫厘，谬以千里" | 误差传播、蝴蝶效应 |

## 七、西方名句

- **"一切可以简单化的事物，都应该简单化，但不能更简单。"** ——爱因斯坦（[[奥卡姆剃刀究竟是什么？]]：最简原则）
- **"重复做同一件事，却期待不同的结果，这就是疯狂。"** ——爱因斯坦（归纳逻辑失效）
- **"我思故我在。"** ——笛卡尔（演绎推理的起点）
- **"飞矢不动" / "阿喀琉斯追不上乌龟"** ——芝诺（极限悖论）
- **"数学是唯一不欺骗我们的科学。"** ——笛卡尔
- **"上帝创造了整数，其余都是人的工作。"** ——克罗内克
- **"数学中没有一无所用的真理。"** ——罗素

## 使用建议

- 可作为逻辑课开场的"猜一猜"互动素材：让学生先说出谚语，再揭示背后的逻辑类型
- 与[[选择理论]]（决策偏误）、[[经济学的思维方式]]（机会成本、激励）结合讲解
- 每类谚语配一个生活案例，帮助学生从"听懂"到"会用"
