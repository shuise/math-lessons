# 谚语与名句中的数学逻辑

汇总知识库中隐含数学逻辑的谚语、名句，按逻辑类型分类。可用于逻辑思维教学素材。

## 一、条件与必要条件

| 谚语 | 隐含逻辑 |
|------|----------|
| "皮之不存，毛将焉附" | 必要条件：皮是毛的前提，p→q，逆否等价 |
| "覆巢之下，安有完卵" | 必要条件：整体被破坏，个体必受影响 |
| "不入虎穴，焉得虎子" | 必要条件：不冒风险就无法获得结果 |
| "人无远虑，必有近忧" | 条件命题：无远虑 → 近忧 |
| "知己知彼，百战不殆" | 充分条件：知己且知彼 → 百战不殆 |
| "学而不思则罔，思而不学则殆" | 两个必要条件缺一不可（与逻辑） |

## 二、归谬与反证

| 谚语 | 隐含逻辑 |
|------|----------|
| "自相矛盾" | 逻辑矛盾：同时主张 p 与 ¬p |
| "此地无银三百两" | 欲盖弥彰，反证法思维 |
| "城门失火，殃及池鱼" | 因果链的传递（演绎推理） |
| "覆水难收" | 沉没成本不可逆 |
| "塞翁失马，焉知非福" | 否定命题未必为假，信息不完备 |

## 三、集合与分类

| 谚语 | 隐含逻辑 |
|------|----------|
| "物以类聚，人以群分" | 分类与聚类 |
| "白马非马"（公孙龙） | 集合与元素不同层次（元素 ≠ 集合） |
| "挂羊头卖狗肉" | 名义分类与实际归属不一致 |
| "五十步笑百步" | 同类比较，相对量的差异 |

## 四、博弈与选择

| 谚语 | 隐含逻辑 |
|------|----------|
| "鹬蚌相争，渔翁得利" | 囚徒困境：非合作博弈两败俱伤 |
| "三个和尚没水喝" | 搭便车问题、边际激励失效 |
| "三个臭皮匠，顶个诸葛亮" | 与上面对立——群体决策能否奏效取决于结构 |
| "宁为鸡头，不为凤尾" | 偏好排序，非传递性偏好 |
| "两害相权取其轻" | 决策：比较期望损失 |

## 五、概率与统计

| 谚语 | 隐含逻辑 |
|------|----------|
| "不怕一万，就怕万一" | 小概率事件也不能忽略（尾部风险） |
| "天上不会掉馅饼" | 概率为 0 的期望 |
| "天下没有免费的午餐" | 机会成本恒存在（[[经济学的思维方式]]） |
| "祸不单行" | 常常是确认偏误/记忆偏差的错觉 |

## 六、极限与累积

| 谚语 | 隐含逻辑 |
|------|----------|
| "一尺之棰，日取其半，万世不竭"（庄子） | 无限细分、极限概念 |
| "不积跬步，无以至千里" | 累积求和（级数收敛） |
| "九层之台，起于累土" | 递归与累积 |
| "锲而不舍，金石可镂" | 重复操作、迭代 |
| "差之毫厘，谬以千里" | 误差传播、蝴蝶效应 |

## 七、西方名句

- **"一切可以简单化的事物，都应该简单化，但不能更简单。"** ——爱因斯坦（[[奥卡姆剃刀究竟是什么？]]：最简原则）
- **"重复做同一件事，却期待不同的结果，这就是疯狂。"** ——爱因斯坦（归纳逻辑失效）
- **"我思故我在。"** ——笛卡尔（演绎推理的起点）
- **"飞矢不动" / "阿喀琉斯追不上乌龟"** ——芝诺（极限悖论）
- **"数学是唯一不欺骗我们的科学。"** ——笛卡尔
- **"上帝创造了整数，其余都是人的工作。"** ——克罗内克
- **"数学中没有一无所用的真理。"** ——罗素

## 八、"励志"传统名言的反逻辑审查

有些名言听起来很励志，但逻辑站不住脚：要么把必要条件说成充分条件，要么只展示成功者、隐藏沉默的失败者，要么定义模糊到无法反驳。它们更像是情绪的燃料，而不是行动的指南。

| 名言 | 表面的励志逻辑 | 逻辑漏洞 | 批判工具 |
|------|----------|----------|----------|
| "不听老人言，吃亏在眼前" | 老人的经验值得听 | 老人言里没应验的那一半没人统计；"吃亏"是事后归因，怎么说都对 | 幸存者偏差、不可证伪 |
| "吃得苦中苦，方为人上人" | 吃苦是成功的必经之路 | 吃苦既非充分也非必要条件：吃了苦没成功的大有人在，没怎么吃苦就成功的人也不少 | 充分/必要条件混淆 |
| "有志者事竟成" | 有志向就一定能成 | 志向只是必要不充分条件；事不成时被解释为"志不坚"，永远无法反驳 | 不可证伪 |
| "只要功夫深，铁杵磨成针" | 坚持投入必有结果 | 忽略成本与机会成本：直接买根针更快更省；它从不比较"值不值得" | 沉没成本、机会成本 |
| "天道酬勤" | 勤奋必有回报 | 只统计了又勤又成功的；又勤又不成功的沉默不语 | 幸存者偏差 |
| "一分耕耘，一分收获" | 投入与产出成正比 | 产出还取决于方向、方法、环境与运气，投入甚至可能为负 | 相关性≠因果 |
| "失败是成功之母" | 失败催生成功 | 失败后不反思照样失败；它也不保证失败了一定会成功 | 因果未验证、赌徒谬误 |
| "苦尽甘来" | 先苦后甜 | "先苦"与"后甘"只是时间先后，先后不等于因果 | 先后≠因果 |
| "大难不死，必有后福" | 大难是后福的预兆 | 劫后余生者后来过得平淡的没人说；两件事本无关联，却被连起来 | 幸存者偏差、事件独立性 |
| "天生我材必有用" | 每个人都有价值 | "有用"定义太宽，任何结局都能算"有用"，无法反驳 | 不可证伪 |
| "善恶终有报" | 行为必有报应 | 报应期限无限，永远无法检验；只记得应验的个案，忘掉落空的 | 不可证伪、确认偏误 |
| "坚持就是胜利" | 坚持必然成功 | 方向错了，坚持只会让错误更大；"坚持多久"没有边界 | 不可证伪、沉没成本 |

**四步审查法（对任何励志格言）**
1. **它是全称命题吗？** 换成"所有……都……"读一遍，看还站不站得住。
2. **失败者在哪里？** 说这句话的人是不是只展示了成功样本？
3. **反例能反驳它吗？** 如果任何反例都能被解释掉，这句话就没有信息量。
4. **它指导行动吗？** 除了让你"更努力"，它还能给出具体、可检验的步骤吗？

## 使用建议

- 可作为逻辑课开场的"猜一猜"互动素材：让学生先说出谚语，再揭示背后的逻辑类型
- 与[[选择理论]]（决策偏误）、[[经济学的思维方式]]（机会成本、激励）结合讲解
- 每类谚语配一个生活案例，帮助学生从"听懂"到"会用"
- 第八类可做"格言辩论"：正方用励志名言鼓士气，反方用四步审查法挑逻辑漏洞——练习识别"哪句话更有信息量"
