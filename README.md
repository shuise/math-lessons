# 数学课程 —— 小学到初中

一套面向零基础的系统性数学课程，覆盖小学算术到初中代数。

## 课程列表

### 小学阶段 — 算术与基础代数

| # | 课程 | 说明 |
|---|------|------|
| 1 | [整数与四则运算](lessons/整数与四则运算/index.html) | 整数的认识、加减乘除、五大运算定律 |
| 2 | [小数与分数](lessons/小数与分数/index.html) | 小数的意义、分数概念、约分通分、分小互化 |
| 3 | [因数与倍数](lessons/因数与倍数/index.html) | 因数倍数、质数合数、最大公因数与最小公倍数 |
| 4 | [百分数](lessons/百分数/index.html) | 百分数的意义、互化、折扣利率等应用 |
| 5 | [比与比例](lessons/比与比例/index.html) | 比的意义、比的基本性质、正反比例 |
| 6 | [简易方程](lessons/简易方程/index.html) | 用字母表示数、等式的性质、一元一次方程 |

### 初中阶段 — 有理数到实数，整式到分式

| # | 课程 | 说明 |
|---|------|------|
| 7 | [有理数](lessons/有理数/index.html) | 正负数、数轴、相反数、绝对值、有理数运算 |
| 8 | [实数](lessons/实数/index.html) | 平方根、立方根、无理数、实数 |
| 9 | [整式](lessons/整式/index.html) | 代数式、整式运算、幂运算、乘法公式、因式分解 |
| 10 | [分式](lessons/分式/index.html) | 分式的概念、分式运算、分式方程 |

## 课程特色

- **零基础友好** — 每个概念从最基础讲起，不预设学生已经理解
- **实例驱动** — 用生活场景引入数学概念，联系实际
- **步骤拆解** — 所有例题按步骤展开，讲清"为什么"和"怎么做"
- **六大板块** — 每课包含：知识名称 → 定理/公理 → 解释 → 关键概念 → 例题 → 练习
- **自成体系** — 课程之间有序衔接，从整数逐步延伸到分式方程
