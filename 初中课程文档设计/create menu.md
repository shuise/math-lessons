# 课件目录生成

1. 严格参考课程目录 _content.md 中的元数据
2. 生成课件目录 menu.md，可以做细节完善补充，可以增加一定难度，但不允许超出这个范围
3. 生成的 menu.md 中的内容要严格按照逻辑顺序组织，要保证系统化


## 生成的前置工作
1. 运行 tools/parser_all.py，解析课本
2. 根据解析结果提取知识点，按逻辑顺序组织课件目录


## 生成后的动作
1. 结合 _content.md 中的元数据，核对生成的 menu.md 内容，确保内容覆盖
2. 检查 menu.md，确保内容逻辑关系、顺序正确
3. 整体检查，确保没有梳理遗漏，补齐了所有断点
4. 最后用合格六年级学生的眼光整体再核对一遍，确保可以理解可接受
