## 阶段一：数 — 从"数数"开始

### 1. 自然数、零与十进制
- 一一对应（数羊、结绳记事）
- 记数符号的演变（埃及象形→罗马数字→印度-阿拉伯数字）
- **位值制**：为什么 111 的三个"1"不一样大？
- **零**：印度人 9 世纪的革命——零作为占位符
- 十进制：为什么是 10？还有哪些常见的其他进制？

### 2. 分数
- 起源：分饼、分地——"不够分"怎么办？
- 真分数、假分数、带分数
- 等值分数：为什么 1/2 = 2/4 = 3/6？
- 通分与约分（找公分母）
- 分数四则运算（加减乘除）
- 倒数（古巴比伦的 igum/igibum）

### 3. 负数
- 起源：中国人的算筹（红正黑负）→ 印度人的"债务"→ 笛卡儿的数轴
- 用欠债、温度计、楼层（地下）理解负数
- 数轴：正数在右，负数在左，零在中间
- 正负数运算规则（为什么负负得正？用数轴和"欠债取消"解释）
- 绝对值：到零的距离


### 补充1. 计算的方法和技巧
- 其实没有乘法，所谓乘法，也只是加法的变形（加上乘法口诀表），是加法的快捷方式
- 常见计算技巧：抵消，裂项，找规律等


### 补充2. 奥数尝试
- 给出10 个左右的奥数题，符合本阶段的知识点
- 奥数题给出思路提示（相关的知识和方法），给出答案，都需要点击查看


### 补充3. 数字的发现与发明
- 大自然中的数字
- 数理逻辑推导出来的数字，创造后又用回到现实中「雨伞定理」
- 主要的几次创作，以及创造者的故事，创造的故事
- 数学的约定与确定的唯一解

## 阶段二：式 — 从"数"到"字母"

### 4. 代数式与字母表示数
- 起源：韦达（16 世纪）和笛卡儿——用字母代替数
- 什么是代数式：数字 + 字母 + 运算符号
- 代数式的值：把字母换成具体数字
- 单项式与多项式
- 系数、次数、常数项

### 5. 整式运算
- 同类项与合并（花拉子米的"对消"）
- 分配律：a(b + c) = ab + ac
- 多项式乘法（FOIL）：(a+b)(c+d) = ac + ad + bc + bd
- 完全平方公式：(a+b)² = a² + 2ab + b²（用面积图解释）
- 平方差公式：(a+b)(a-b) = a² - b²

### 6. 因式分解与分式
- 因式分解：把多项式"拆回"乘法形式
- 提公因式法
- 十字相乘法（二次三项式 → 两个一次因式相乘）
- 分式：分母含字母的代数式
- 分式的基本性质与约分、通分
- 分母为什么不能为零？

## 阶段三：方程 — 天平上的未知数

方程可以将问题描述转化为代数表达式，把推导解决问题的过程简化成求解方程。其实等于替代了思考，从而简化问题，降低了对人的要求。

举例子：古代解方程的困难，射雕英雄传中的瑛姑。

### 7. 一元一次方程
- 起源：古巴比伦泥板问题、古埃及阿姆士纸草书、花拉子米的"还原与对消"
- 天平比喻：等式两边平衡
- 等式的性质：两边同时加减乘除（不为零）同一个数，等式仍然成立
- 解法（用逻辑推导每一步，不是背步骤）：
  - 去分母 → 两边乘公分母（等式性质：乘）
  - 去括号 → 分配律展开（已学：课件 5）
  - 移项 → 两边加减同一个数（等式性质：加减）
  - 合并同类项 → 花拉子米的"对消"（已学：课件 5）
  - 系数化为 1 → 两边除以系数（等式性质：除）
- 检验：代入原方程

### 8. 分式方程
- 起源：古巴比伦的倒数问题（igum/igibum）
- 核心思路：去分母 → 化为一元一次方程
- 致命陷阱：增根——为什么必须检验？
  - 去分母时乘了含未知数的式子，可能引入"伪解"
  - 检验方法：代入原方程，看分母是否为零
- 解法步骤与检验（已学基础：课件 2 分数、课件 6 分式、课件 7 一元一次方程）

### 9. 一元二次方程
- 起源：古巴比伦的几何解法 → 花拉子米的"凑完全平方" → 邦贝利与虚数
- 标准形式：ax² + bx + c = 0（a ≠ 0）
- 四种解法（每种解释由来，从基本知识推导）：
  - 直接开平方法：x² = k → x = ±√k（已学：课件 5 平方根概念）
  - 配方法：花拉子米的几何思路——把 x² + bx 拼成 (x + b/2)²（已学：课件 5 完全平方公式）
  - 公式法：由配方法推出求根公式 x = (-b ± √(b²-4ac)) / 2a
  - 因式分解法：化为 (x-m)(x-n)=0 → x=m 或 x=n（已学：课件 6 十字相乘）
- 根的判别式 Δ = b² - 4ac：
  - Δ > 0：两个不等实根
  - Δ = 0：两个相等实根
  - Δ < 0：无实根（邦贝利发现：引入虚数后有解，但不要求）
- 韦达定理：x₁ + x₂ = -b/a，x₁·x₂ = c/a（用因式分解推导）

## 阶段五：几何进阶 — 平行与三角形

### 13. 相交线与平行线

- 角平分线的性质：角平分线上任意一点到两边距离相等

## 阶段九：函数 — 描述变化的语言

### 23. 平面直角坐标系
- 起源：笛卡儿——把几何问题转化为代数问题
- 坐标：有序数对 (x, y) 对应平面上的点
- 象限：四个象限，各象限点的符号特征
- 用坐标表示地理位置（经纬度类比）
- 用坐标表示平移

### 24. 一次函数
- 函数的概念：输入 → 输出，每个 x 对应唯一 y
- 正比例函数：y = kx（过原点，k 是斜率）
- 一次函数：y = kx + b（k 是斜率，b 是截距）
- 图象：一条直线。k>0 上升，k<0 下降
- 用待定系数法求解析式
- 一次函数与方程、不等式的关系

### 25. 二次函数
- 二次函数：y = ax² + bx + c（a ≠ 0）
- 图象：抛物线，a>0 开口向上，a<0 开口向下
- 顶点、对称轴、最值
- 二次函数与一元二次方程：图象与 x 轴的交点 = 方程的根
- 实际问题：最大利润、最佳射程
- 黄金分割数（拓展阅读）

### 26. 反比例函数
- 反比例函数：y = k/x（k ≠ 0）
- 图象：双曲线（两支，关于原点对称）
- 性质：k>0 在一三象限，k<0 在二四象限
- 反比例关系：x 越大 y 越小
- 生活中的反比例关系（拓展阅读）

## 阶段十：几何综合

### 27. 旋转
- 旋转三要素：旋转中心、旋转方向、旋转角度
- 旋转的性质：对应点到旋转中心距离相等
- 中心对称：旋转 180°
- 中心对称图形：平行四边形、圆、正六边形
- 图案设计（课题学习）

### 28. 圆
- 圆的定义：到定点距离等于定长的点的集合
- 弦、弧、圆心角、圆周角
- 垂径定理：垂直于弦的直径平分弦
- 圆周角定理：圆周角 = 圆心角的一半
- 点和圆、直线和圆的位置关系（相离、相切、相交）
- 切线长定理
- 正多边形和圆
- 圆周率 π 的故事（拓展阅读）
- 弧长与扇形面积

### 29. 相似
- 相似：形状相同，大小不同
- 相似三角形的判定（AA、SAS、SSS）
- 相似三角形的性质：对应边成比例
- 位似：相似 + 对应点连线交于一点
- 奇妙的分形图形（拓展阅读）

### 30. 锐角三角函数
- 正弦、余弦、正切的定义（直角三角形中的比）
- 特殊角（30°、45°、60°）的三角函数值
- 解直角三角形：已知部分元素求其余元素
- 实际问题：测高、测距
- 一张古老的"三角函数表"（拓展阅读）

### 31. 投影与视图
- 投影：中心投影与平行投影
- 三视图：主视图、俯视图、左视图
- 由三视图还原立体图形
- 制作立体模型（课题学习）
- 视图的产生与应用（拓展阅读）

## 阶段十一：统计与概率

### 32. 数据的收集与整理
